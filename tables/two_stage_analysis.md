# 两阶段布局与密度自适应：可行性分析（2026-08-21）

> 回答用户问题：①当前热区规避能力来源；②"先拓扑求低/零 SWAP 嵌入，再噪声优化"
> 是否可行；③模型自动判别线路密度（低密度强化噪声、高密度优先降 SWAP）是否有效。
> 结论基于实测数据与源码级机制分析；涉及管线结构变更的建议**未实施**（按用户约束）。

## 1. 当前热区规避能力的来源（三层机制）

1. **RL 策略**：训练设备节点特征含 7 维校准特征，终局奖励 D_eff = D_topo +
   λ_n(D_noise − D_topo)——学会把交互对放上干净耦合器
2. **局部搜索**：D_eff 代价的交换改进
3. **竞技决胜**：swap 规则 +2 SWAP 容差内取保真度最高者

实测：2Q 误差加权均值全场最优（0.0035-0.0038 vs 盲目 O1 的 0.012-0.017）。
**代价**：噪声感知单目标加权把电路打散，QUEKO dense 上 85 SWAP。

## 2. 关键发现：静态"零 SWAP 嵌入"在这些线路上不存在

- QUEKO dense (3,4) 线路交互图含 **20 个三角形**（45CYC 结构），而网格拓扑
  **无三角形**——任何静态布局都不可能让全部交互对相邻
- qiskit O1/O3 报出的 0 SWAP 是**管线级效果**而非布局质量：实测 SabreLayout
  路由插 71-74 个 SWAP → VF2PostLayout 重标记 + 路由后酉综合吸收置换 → 输出
  0 SWAP。O1 的初始布局仅 18/41 交互对相邻（比我们的布局更差）
- 含义：**布局层能做到的下限 ≈ 71 SWAP（SabreLayout 自己的路由结果）；
  "零 SWAP"需要路由后重标记 + 酉综合等管线机制**，单靠布局搜索不可达

## 3. "先拓扑后噪声"两阶段：已有机制 + 实测验证

当前管线已含两阶段结构：λ=0 纯拓扑候选 + 噪声候选 → sabre 代理评分竞技 →
swap 规则 +2 容差保真度决胜（= 嵌入确定后选干净边）。

实测（QUEKO dense，6 条）：
| 管线配置 | SWAP（均值） |
|---|---|
| 噪声感知单目标（fid 规则） | 85 |
| λ=0 纯拓扑 + swap 规则 | 54-97（≈79） |
| SabreLayout 路由下限 | 71-74 |

纯拓扑管线已达布局层下限附近。**结论：两阶段方案有效且已就位；其天花板 =
布局层下限，与 O1/O3 的剩余差距（0 vs ~75 SWAP）来自路由后管线机制
（VF2PostLayout + 酉综合）——属于方案结构变更，未实施。**

## 4. 密度自适应判别：实测不成立

- 每线路"fid 规则 vs swap 规则"胜者与交互图密度的关系：fid 胜出组密度均值
  0.179 vs swap 胜出组 0.201——**无可靠阈值**，密度不能预测哪个规则更好
- 理想判别器（每线路取两规则更优者）vs 噪声感知 O3：QUEKO dense 0/30、
  sparse 0/10、MQTBench small 2/15、medium 1/14——**即使判别完美也只赢
  3/59 条**，瓶颈不在规则选择而在布局搜索能力差距

## 5. 综合结论与建议

1. 两阶段（拓扑优先 + 噪声决胜）**方向正确且已实现**，维持现状即可
2. 密度显式判别**无收益**（规则层面无可区分信号），竞技机制本身已隐含密度
   适应——不引入判别器
3. 与噪声感知 O3 的真实差距 = **路由后管线机制**（重标记 + 酉综合，公开
   算法）——若采纳，属于结构变更（等价于 SabreSwap 子程序定位），需用户决策
4. 布局层 RL 的独立价值已收敛为：边质量最优（mean2q 证据）+ 多目标可学 +
   跨拓扑泛化（见 tables/cross_topo/）
