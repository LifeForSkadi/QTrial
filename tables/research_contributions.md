# QTrial 研究创新点定位（竞赛叙事）

## 定位声明

QTrial 是 **CO-MAP 的研究型进阶**：保留其"稀疏终局奖励 + 图注意力编码 + 指针解码"的
核心范式，在五个维度提出原创算法改进，全部经实验验证。默认管线**不采纳任何外部编译
器的输出**（SABRE 仅作为路由子程序与评测基线，pytket/MQT QMAP 仅作为对比基线）；
混合竞技采纳（--ensemble）是可选工程增强，不作为研究贡献。

## 五项研究贡献（CO-MAP → QTrial）

### 贡献 1：噪声感知映射（QTrail 核心，CO-MAP 完全缺失）

**问题**：CO-MAP 的耦合图只有拓扑；真实芯片上不同比特/耦合器的误差差异达数倍。
**方法**：① 校准数据（T1/T2/1Q/2Q/读出误差）经设备级 min-max 归一化后作为 7 维
设备节点特征输入 GNN；② 噪声加权距离矩阵（边权 = 1 + α·误差因子 + β·T1 惩罚）
融入终局奖励，形成 `D_eff = D_topo + λ_n(D_noise − D_topo)` 的拓扑-噪声联合优化。
**免重训泛化**：同一权重对同拓扑不同校准数据自归一化适配（天衍 download_config 实测接口）。
**证据**：消融实验——布局级加权 2Q 误差 **-5.4%**（拓扑代价仅 +0.09%）；端到端估计
保真度达 SABRE O1 的 2~3.7 倍；QUEKO 高密度档保真度优势达 270 倍。

### 贡献 2：时序感知程序图（针对 CO-MAP 静态图的盲区）

**问题**：CO-MAP 的交互图把门压缩成无时序的边权——45 周期的时序结构（哪些交互
必须并发、哪些贯穿全程）完全丢失。
**方法**：贪心分层（layer(q) = 两端比特上次层+1）后，边权 `+= α × 交互层跨度数`——
强调跨时间层的持续耦合（QFT 链式交互受益），让布局阶段直接感知时序。
**证据**：纯模型头对头——SWAP -0.7%、深度 -2.4%、RL 直接胜场 7/30 → 9/30。

### 贡献 3：深度感知稀疏奖励（保持 CO-MAP 特色前提下的奖励扩展）

**问题**：CO-MAP 的终局奖励 Σ2d·w 优化串行代价，对并行执行（深度）无感知。
**方法**：在**终局一次性稀疏结构不变**的前提下，加入负载均衡惩罚项
`Σ_q h(q)² / Σ_q h(q)`（h(q)=比特交互负载）——惩罚热点比特，布局偏向低深度。
λ=0 严格还原 CO-MAP 原奖励（测试锁定）。
**证据**：三规则分层评测中 depth 规则使三层深度收窄 3-7% 且 SWAP 几乎不变。

### 贡献 4：多起点自适应局部搜索（CO-MAP 后处理的系统化重构）

**问题**：CO-MAP 的后处理是单起点随机交换+patience——探索不足且无结构。
**方法**：① 多起点（采样解码 + 乱序贪心 + 贪心 ×10，去重取优）；
② 阶段化搜索（探索期：热比特链式大扰动跳出局部最优；精化期：首改善交换）；
③ 增量代价计算 O(n)/步。
**证据**：距 QUEKO 完美嵌入下界 1.7×（仍有空间但显著优于随机起点）。

### 贡献 5：多拓扑 + 大 N 混合训练（单一策略的跨设备泛化）

**问题**：CO-MAP 每拓扑单独训练；真实平台家族（287/294/504）拓扑各异。
**方法**：7 拓扑设备池（网格族/Sycamore 式砖墙/heavy-hex/22×22）+ QASMBench 433 比特
线路混合训练；策略网络对任意设备规模通用（设备编码器为图神经网络）。
**证据**：跨拓扑评测——multi7topo 在主场（15×7）仅损失 1.5%，在最异质拓扑
（heavy-hex-115）上泛化优于专用模型（25.8 vs 26.4，RL 直接胜场 3 vs 0）。

### 贡献 6（研究假设的严格验证与诚实结论）：路由感知终局奖励实验

**假设**：CO-MAP 的静态代价 Σ2d·w 与真实路由脱节；把终局奖励升级为候选布局
经 SabreSwap 的真实路由 SWAP 数（稀疏结构不变），应提升布局的路由适配性。
**方法**：oracle 电路真实线路优先（图池存储 QASM）、随机图合成边染色分层线路；
并实现 swap+噪声联合变体。
**验证结论（38 线路 × 4 模型头对头，纯研究管线）**：
- 合成线路 oracle：仅深度改善，SWAP 无迁移——合成/真实线路路由景观差异（实验发现）
- 真实线路 oracle：单次运行 SWAP -2.1%/深度 -8.6%，但复跑差异在运行噪声内
- 联合 oracle（swap+噪声）：无稳健增益
- **总判定：路由 oracle 在 ≤25 比特 episode 的当前设置下无稳健提升——静态代价
  配合时序/噪声/深度增强已是强学习信号。负结果作为研究记录保存**（诚实性价值：
  避免后来者重复该路径），静态 v2 模型为最终方案。

### 贡献 7（tket 机制借鉴实验，如实记录）：深度感知路由 / 嵌入感知搜索 / 紧凑性正则

借鉴 tket 的 LexiRoute（Cowtan et al. QIC 2019）与图同构放置思想，自主实现三条路径：
- **A 深度感知路由器**（`pipeline/lexiroute.py`）：前沿分层 + 最短路径首边候选 +
  收益/势能字典序评分 + 禁忌。态矢量等价正确性验证通过；但启发式强度未达
  SabreSwap（缺前瞻层/衰减机制）——保留为研究实现与可选路由方法，默认使用 sabre
- **B 嵌入感知局部搜索**：以"相邻交互对数"为结构匹配目标的定向交换算子，
  代价容差内接受嵌入改善。**实测有效：深度 -6.2%、SWAP -0.8%（零代价）**，默认启用
- **D 紧凑性正则**：终局奖励加入布局物理直径惩罚（稀疏结构不变），鼓励紧凑布局。
  c0.05 模型训练完成，验证集与 v2 持平

诚实性声明：A 未达预期（正确的简化实现 ≠ 有竞争力的启发式强度），B 温和有效，
D 中性偏微正——三条路径的实验结论全部如实记录。

- **三目标决胜规则**（swap/fidelity/depth 可切换）：同一策略网络下的多目标决策框架
- **路由感知候选择优**：以学习式先验为起点的多试验布局搜索（仅使用 SabreSwap
  作为路由评估器——公开算法作为子程序，不构成成果依赖）

## 贡献 8：Cqlib 注入接口（天衍平台原生管线对接，2026-08-21）

**动机**：天衍量子计算云平台的原生映射管线（cqlib `transpile_qcis`）为评审现场
的实际执行入口。研究方案与平台管线的协同方式：**QTrial 提供学习式初始布局，
平台管线执行原生 MCTS 路由**——布局与路由各取所长。

**实现**（`pipeline/cqlib_route.py` + `Mapper(routing_method="cqlib")` + CLI
`--routing cqlib`）：
- RL 多起点布局 + 自适应局部搜索 → `initial_layout` 注入 cqlib `transpile_qcis`
- 平台对象双模式：有 `TIANYAN_LOGIN_KEY` 用真实 TianYanPlatform 配置；
  无 key 用合成配置 MockPlatform（接口一致，评审现场无缝切换）
- 攻克 cqlib 接口约束：initial_layout 必须覆盖全部平台比特（恒等门补全 +
  满射布局）；`generate_qubit_mapping` 遇 measure 即停（测量剥离后回挂）；
  `QcisToQasm` 不支持 SWAP（分段转换 + 段间插 swap）；输出含 qelib1 之外的
  门 sx/sxdg（sanitize 统一改写）
- 正确性验证：布局生效性（cqlib 精确采纳注入布局，打散布局下 SWAP>0）
  + 态矢量等价 1.000000（位置追踪 unmap，处理幻影 swap）
- 统一口径：输出经 decompose_to_platform 后 compute_metrics 度量，
  与 QTrial/SABRE/tket 完全同口径

**定位声明**：cqlib MCTS 为平台方公开算法，注入接口是**对接工程**而非研究贡献；
研究贡献仍为布局策略与管线设计。对比实验见 `tables/cqlib_inject/`。

### 贡献 8 评测结果（tables/cqlib_inject/report.md，截尾均值口径）

**≤10 比特（15 条）**：SWAP Cqlib 原生最强 3.77 < SABRE O1 3.85 ≈ pytket 3.85
< QTrial+SABRE 4.77 < QTrial+Cqlib 6.46；深度 QTrial+SABRE **90.23 最优**
（tket 96.15、Cqlib 原生 86.38）；保真度 QTrial+SABRE **0.74** ≈ QTrial+Cqlib
0.72 > tket 0.71 > Cqlib 原生 0.61 > O1 0.49（**1.5× O1**）。

**11-50 比特（14 条，qwalk_25 病态线路以截尾消除）**：SWAP O1 252.00 最优，
QTrial+Cqlib 160.09 vs Cqlib 原生最强 169.22；深度 QTrial+Cqlib **899.00 最优**
（O+S 1152.67、O1 1147.25、tket 1447.67、Cqlib 原生 1168.22）；
2Q 深度 QTrial+Cqlib **812.27**；保真度 QTrial+SABRE 0.23 ≈ tket 0.22 >
QTrial+Cqlib 0.21 > O1 0.16 > Cqlib 原生 0.13。

**关键结论**：
1. **统一平台基口径后 tket 的深度优势消失**（此前 2-3× 领先是 cx 口径假象）；
   QTrial 双后端在两层均为深度最优/次优——深度目标可达
2. Cqlib 原生：小线路 SWAP 最优、深度最差；大线路频繁超时（graphstate_50 两
   目标 >600s、qwalk_25 全超时）——**不适合竞赛实时编译路径**
3. QTrial+Cqlib 注入：深度与保真度占优（两层保真度均显著超 Cqlib 原生与 O1），
   SWAP 弱于原生 Cqlib——注入把"深度+保真度"目标交给 RL 布局、SWAP 交给 MCTS，
   是平台原生管线下的合理分工；接口保留为 opt-in
4. 51-105 层按用户决策砍掉（cqlib 家族超时无数据可比）

## 诚实负结果专题：布局层机制对照实验（2026-08-21，用户主导的取证）

用户目标：证明布局方案（稀疏奖励 RL + 噪声感知）的创新性与必要性。设计并执行
三组对照实验，全部如实记录：

**实验 1：噪声感知 O1/O3 基线**（tables/noise_aware/，qiskit Target 驱动
VF2PostLayout 打分）。结论：MQTBench 全部 29 条线路可无 SWAP 嵌入，感知 O3
（0 SWAP + 低误差嵌入）保真度全面超过 QTrial（fid 规则 1/15、1/14 胜）。
QTrial 的 2Q 误差加权均值全场最优（边质量强），但 SWAP 开销压过边质量收益。
盲目 O1→感知 O1 的跳跃说明"是否有噪声感知"贡献大部分收益。

**实验 2：QUEKO 高密度决定性实验**（tables/queko_noise/）。关键发现：
①QUEKO dense 交互图含 20 个三角形——网格无三角形，**静态零 SWAP 嵌入在布局层
不可能**（此前"无 SWAP 嵌入"假设错误）；②O1/O3 的 0 SWAP 是管线级效果
（SabreLayout 路由 71-74 SWAP → VF2PostLayout 重标记 + 路由后酉综合吸收置换），
非布局质量；③纯拓扑管线 SWAP 54-97 ≈ SabreLayout 下限 71-74——**布局层 RL 已达
布局可达的上限**，剩余差距来自路由后管线机制（结构变更，未实施）。

**实验 3：缺陷强度敏感性扫描**（tables/defect_sweep/，×0/×2/×3/×5）。
结论：QTrial 保真度对缺陷强度**不变**（0.500±0.003，噪声规避完全补偿），
盲目 O1 从 0.4976 单调退化至 0.3181（1.56×）——噪声感知优势真实且稳健；
×0 对照下 QTrial ≈ 盲目 O1（无波动则噪声机制零收益，符合机制前提）；
感知 O3 在全部档位最优（0.565-0.568）。

**实验 4：密度自适应判别**（tables/two_stage_analysis.md）。结论：交互图密度
不能预测 fid/swap 规则哪个更优（胜出组密度 0.179 vs 0.201 无区分）；理想判别器
vs 感知 O3 仅 3/59 胜——瓶颈是布局搜索能力而非规则选择；两阶段（拓扑优先+噪声
决胜）机制已内置且已达布局层上限。

**实验 5：跨拓扑验证**（tables/cross_topo/，multi7topo 模型 × 6×6/heavy-hex-115/
Sycamore-53）。结论：RL 噪声规避**跨架构泛化**（vs 盲目 O1 保真度 30/32、30/32、
21/32 胜），但感知 O3 仍整体领先（1-4/32 胜）——与 105 比特结论一致。

**综合判断**：噪声感知 RL 布局的独立价值 = ①边质量最优（mean2q 全组最低）
②噪声规避跨拓扑泛化 ③对缺陷强度稳健；但"与噪声感知 VF2 试验竞争保真度第一"
在当前机制下不成立——差距在 SWAP 与路由后管线机制。诚实叙事建议：RL 布局 =
"学习式多目标布局搜索组件"，强项为噪声稳健性与泛化，而非单指标第一。

**指标修复**：twoq_depth 旧实现为"2Q 门总数"（非深度），已修为 DAG 最长路径
计数 + 回归测试（84 测试）；cqlib_inject 旧表该列加注，新表全部修复后口径。

## 贡献 9：Target 后处理管线（opt-in，2026-08-21，用户采纳）

**定位**：qiskit O1/O3 预设管线（噪声感知 Target 驱动）作"公开算法子程序"
（与 SabreSwap 同级定位）——布局由 QTrial 提供（RL 多起点 + LS + 竞技池，
池纯净性不变：无外部布局），路由后重标记/酉综合阶段吸收置换。

**实现**：`pipeline/target_post.py` + `Mapper(target_post=, target_post_opt=)` +
CLI `--target-post [--target-post-opt 3]`。**后感知竞技评分**：候选布局按
"后处理后的真实结果"评分（布局×管线联合选择）。默认关闭，原研究管线
逐字节不变（85 测试含默认路径回归 + 态矢量等价验证）。

**实测**（tables/target_post/report.md，69 条线路，opt=3 版）：
- SWAP 全 0（QUEKO dense 92→0、mqt-med 291→0——置换吸收机制生效）
- 保真度 vs 原管线：**62/69 胜**（dense 30/30、sparse 10/10、med 12/14）
- vs 噪声感知 O3：**13/69 胜**——mqt-med **7/14**（0.2576 vs 0.2867）、
  dense 5/30、small 1/15、sparse 0/10；深度在 med 组反超（1000.3 vs 1033.6）
- 候选生成杠杆的完整探索（用户主导）：①同流扩池 14→34 无效（RNG 位移丢旧
  胜者，均值微升胜场降）；②多种子池有效——4 种子全量（74 候选）四组均值全升
  （dense +6.2%）、vs 感知 O3 13→16 胜；③**多种子×少候选更优**：8 种子×top-3
  （48 候选，评分量更少）dense 组 0.1455 创历史最佳、vs O3 8/30 胜——盆地
  多样性 > 同盆地深挖（用户提出的分配原则经实证成立）。默认配置 =
  --target-post-opt 3 --target-post-seeds 8 --target-post-top 3
- 剩余差距 = O3 的 50 次 VF2 结构引导试验分布 vs 我们静态代价引导的候选分布
  ——数量杠杆已探明边界，性质差距仍在（dense 0.146 vs 0.164、small 0.812 vs
  0.830），待用户决定是否走结构引导候选或奖励重训闭环
- 诚实结论：target_post 把差距从"管线级"压缩到"布局试验数量级"；
  RL 布局的独立价值保留在：噪声稳健性（defect_sweep）+ 跨拓扑泛化
  （cross_topo）+ 多目标竞技框架

## 贡献 10：qiskit-free 纯自研管线（qtrail/pure/，2026-08-21，用户决策）

**背景**：qiskit 在国内评审语境下不被官方推崇，交付管线依赖 qiskit 可能影响
奖项评定——用户要求竞赛交付链路零 qiskit 依赖（qiskit 仅保留于训练数据处理
与实验对比），qiskit 支撑版保留为内部参照（不交付）。

**实现**（qtrail/pure/ 包，`python -m qtrail.pure_cli`，实测零 qiskit 导入）：
- 自研 OpenQASM 2.0 解析器（qelib1/自定义 gate 递归展开/u/u1/u2/u3/cx/cz/swap）
- 自研电路 IR（指令列表 + 惰性依赖 DAG）与度量（深度/2Q 深度/保真度乘积）
- **自研 SABRE 路由器**（ASPLOS'19 公开论文算法复现：front layer 并行执行 +
  extended set + 逐门衰减权重 + 历史惩罚 + makespan 项）——态矢量等价验证
- **自研后处理栈**（swap 对易推挤 + swap;swap 消解 + cx 对消解 + 尾部置换
  吸收与最终布局重标记 + rz 合并）
- **自研 U3→[rz,sx,x,cz] 分解**（ZYZ 欧拉角 → 5 门 ZXZ 序列，200 随机酉
  数值验证 4e-14；H/X 特例与 qiskit 同款口径）——期间修复度量 bug（相位
