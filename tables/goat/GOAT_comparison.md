# GOAT 编译器对比实验报告（天衍-287 拓扑，105 比特 15×7 网格）

实验脚本：`scripts/benchmark_goat.py`；数据：`tables/goat/goat_rows.jsonl`。
23 条线路 = QUEKO BIGD 20 条（20 比特）+ MQTBench n=15 三条（qft/qaoa/qpeexact）。
统一指标口径：SWAP 展开为 3 CX 后计 2Q 门数；估计保真度用同一套合成校准数据（含缺陷热区）。

## 结果（均值 / 中位数）

| 编译器 | SWAP 数 | 2Q 门数 | 深度 | 估计保真度 | 说明 |
|---|---|---|---|---|---|
| **SABRE O3**（Qiskit=LightSABRE） | **19.7 / 16.0** | 111.1 | 152.3 | 0.182 | SWAP 之王：50 布局试验×重度定点迭代 |
| **pytket**（Quantinuum） | 27.9 / **22.0** | 166.9 | **90.4** | **0.514** | 深度之王：并行感知路由 + 优质放置 |
| **QTrial**（本项目） | 27.2 / 29.0 | 148.7 | 208.5 | 0.213 | 与 O1 持平 + 噪声感知（2×O1 保真度） |
| SABRE O1 | 27.4 / 29.0 | 149.5 | 210.6 | 0.111 | 论文时代默认基线（现已含 LightSABRE） |
| MQT QMAP 启发式 | 38.6 / 39.0 | 184.8 | 151.6 | 0.105 | 本拓扑上默认配置最弱（强项是精确 SAT 模式） |

## 关键发现

1. **"GOAT"在不同指标上是不同模型**：路由 SWAP 数最优 = SABRE O3（重度搜索）；
   深度/保真度最优 = pytket（并行感知路由）；噪声规避最优 = QTrial（保真度 2×O1）。
2. **pytket 的深度优势显著**（90 vs 我们的 208）：其默认路由策略深度感知，值得在报告中
   如实说明并列为可借鉴方向。
3. **MQT QMAP 启发式在 105 比特设备上未调优即表现最弱**；其精确模式（SAT）在 20 比特
   级线路不可行（指数时间），未纳入。
4. Qiskit SABRE = 集成版 LightSABRE（Qiskit 1.2 起 Rust 重写），即我们此前"移动基线"
   分析中的今日基线。

## ML 路线 GOAT 源码评估（calibration-aware RL routing, arXiv 2606.12816）

源码完整可获取（MIT，YTomar79/calibration-aware-rl-routing，3.2MB，含训练代码 +
IBM 三台真机校准数据 + 全量结果）。其论文自报结果（IBM Heron r2 真机校准，
5-10 比特 MQTBench 线路）：

| 方法 | 精确保真度 | 2Q 门数 |
|---|---|---|
| Agent（PPO 图 RL 路由器） | **0.727** | 28.98 |
| SABRE-best20 | 0.440 | 20.24 |
| Target-aware SABRE | 0.481 | 20.29 |

**适配评估**：
- 优势：校准感知保真度路线与我们 QTrail 方向一致，其 +0.25~0.29 绝对保真度提升
  佐证噪声感知的价值
- 决定性限制（其论文自述）：**10 比特以上线路全部 SABRE 占优**——我们竞赛线路
  是 15-20 比特，恰在其失效区间；且其动作图绑定 IBM Heron 树形拓扑，迁移到
  15×7 网格需重写环境 + 10 种子训练（约 2-4 天）
- **结论：不建议完整适配**；建议在报告中引用其论文作为噪声感知方向的第三方佐证
