- 理想分布：qiskit `Statevector`（逻辑序）；
- 经典保真度 = `(Σ √(p·q))²`（Bhattacharyya 平方）；
- TVD；峰值态（支撑 ≤4）命中率；
- GHZ 规模扩展（5/10/15）实测命中 vs 乘积模型预测。
