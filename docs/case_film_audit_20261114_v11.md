## 数据与诚实性

1. **mixed20 是演示负载**：CX 骨架来自 QUEKO BIGD `20QBT_45CYC_.5D1_.1D2_0`（45 CX）；450 个 1Q 门替换为 H/X/Y/Z/S/T/RX/RY/RZ。映射/路由/后处理数字均由 QTrial 在该文件上实际运行得到，但不是 QUEKO 原始成绩。
2. **A1 是部分折叠**：当前生产 `fold_and_relink` 在存在“保留 SWAP”时会整体回退；片中逐 SWAP 判定只应用 11 个可吸收步，A2/A3/B 在该部分折叠结果上运行。
3. **C1/L3 未应用于最终指标**：片中作为候选评估展示；最终 44/127/0.275 来自 A1（部分）+ A2 + A3 + B。
4. **B 是机制示意**：片中 RZ 合并 / SX 对消 / H 吸收为教学动画，不是该案例逐门录制的 B pass 轨迹。
5. **真机 v9 新批次**：7 条 v8 + 3 条 O3 为 tianyan176 真实执行；x5/ghz 系低值来自本批次实测，未做挑选。4 条补跑的 O3 对照仍在队列，未写入表格。
6. **31/31 是发布前审计**，不是 31 条真机执行；tianyan-287 机时不足。
