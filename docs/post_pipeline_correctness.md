# 后处理管线正确性框架（评委口径，2026-11-13）

## A. 总不变式（管线必须同时满足的两条）

**I-语义（交付判据）**：设输入线路 C（逻辑比特 0..n-1）、管线产物
C' 与最终布局 fin（逻辑 i → 最终物理位）。交付语义要求：

  U(C')|0…0⟩ = Π_fin · U(C)|0…0⟩

其中 Π_fin 是把"逻辑比特 i 的读回"从初始嵌入位置搬运到 fin(i) 的
坐标置换（真机执行 C' 后按 fin 读回 = 原线路从 |0⟩ 的读回分布）。

注意（审查 P2-3 修正）：**初始布局 π 只是路由器的内部选择，不进
入交付判据**——凡发生净置换的路由，U(C')|0⟩ ≠ U(C_π)|0⟩（两者
差一个 π→fin 置换）；判据只依赖 (C', fin) 对。紧凑子空间验证
（verify_e2e_production.py）实现即此判据（原线路经 **fin** 嵌入）。

**I-合法**：C' 的门集 ⊆ {rz, sx, x, cz, measure}；每个 cz 端点对在
耦合图 adj 上相邻；所有比特 ∈ [0, spec.n) 且 ∉ disabled_qubits；
无 swap 残留。

**守卫设计**：
- I-语义 的权威验证 = raw-vs-raw Statevector（qiskit 权威实现）：
  输入嵌入初始布局 vs 产物，在同一物理帧（N = max_qubit+1）上比较，
  fid = |⟨ψ₁|ψ₂⟩|² 必须 = 1（数值 1-1e-6）。≤26 比特可全空间验证；
  更大规模因 2^N 内存不可行——由"逐 pass 代数精确性"降级保证
  （见 B），并辅以可计算规模的抽检。
- I-合法 的验证 = 全样本三重扫描（verify_all_legality.py）。

**关键推论（阈值修正）**：B2 组件的数值守卫是"实现正确性"的
探测器——若管线实现正确（恒等式无错），实测 fid 应落在
1 - N_块×1e-6 ~ 1 量级（实践中拟合收敛到 ov≈1-1e-12）；fid 出现
**e-4~e-3 级以上**的偏离才构成恒等式错误证据（守卫边缘的合法
替换本身可产生 ~1.8e-3/块的 fid 下降，e-5 级偏离不能定罪——
审查 P2-4）。

## C. 验证方法论（当前执行）

1. **紧凑子空间法**（verify_e2e_production.py）：产物触碰比特
   压缩映射 0..k-1 + final_layout 嵌入原线路，k 比特 Statevector
   fid=1。覆盖 RL 布局（布局跨度 89 不碍事——只压缩触碰集）。
2. **合法性三重扫描**：门集/相邻性/禁用比特/swap 残留。
3. **>26 比特**：组件级保证（B1 精确性）+ 合法性全扫 + 同代码
   路径的规模外推。诚实边界声明。

## D. 真机可实现性的最终判据

C' 可在真机执行 ⟺ I-合法 ∧ I-语义。I-合法是语法扫描（可全量）；
I-语义在 ≤26 比特上由 Statevector 权威验证，更大规模由 B1 的
代数精确性 + B2 的守卫完备性给出。**任何新 pass 入库前必须**
：(1) 提供其恒等式的数学表述与证明；(2) 通过 fid=1 + 合法性
双检；(3) 通过审查代理复核。
