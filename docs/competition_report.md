## 一、作品概述

量子线路编译（量子比特映射）是每一条量子算法登上真机前必经的一环：超导芯片的耦合器连接是稀疏的，线路中任何一对不相邻比特上的双比特门都必须插入 SWAP 门才能执行，而 SWAP 的代价（两比特门误差、相干时间损耗）远高于普通门。**布局与路由的质量直接决定一条线路在真机上的成败**——对只有 105 个比特的天衍-287 尤其如此。

QTrial 用**稀疏奖励强化学习**解决布局问题：把布局建模为二次分配问题（QAP），以图注意力网络编码线路结构、指针注意力网络逐步生成布局，仅在线路完整映射后给予一次性奖励（终局奖励，无任何中间奖励塑形），配合自批评基线完成 REINFORCE 训练。在此之上实现三项机制创新：**噪声感知映射**（校准数据驱动的特征与噪声加权距离，同一权重跨设备零重训迁移）、**多起点自适应局部搜索**、**深度感知静态奖励**。路由与后处理环节完全自主实现（自研 SABRE 路由器 + 置换共轭后处理栈），**交付管线不依赖任何外部量子软件栈**——评委环境只需安装 PyTorch 等通用依赖即可运行。

系统在 IBM Qiskit 官方 Benchpress 基准（656 条线路，≤105 比特全部纳入）、MQTBench、QUEKO 三套数据集上与五种基线（盲目/噪声感知 O1/O3、pytket）完成分层对比。

**最终基准（587 条线路，QTrial pure fidelity 规则）**：平均估计保真度 QTrial **0.1958**、感知 O3 **0.2444**（QTrial 为其 0.80×）、pytket **0.1869**、盲目 O1 **0.1226**；逐线路胜场（534 条全完成）：vs 感知 O3 **29**、vs pytket **134**、vs 盲目 O1 **226**。分层明细见 §8.2 与 tables/final_report/。

全部映射结果通过态矢量等价验证，并预留天衍-287 真机验证协议。

## 二、榜题契合与"双向赋能"逻辑链路

榜题要求作品"紧扣量子+AI 双向赋能"。本作品的双向链路如下：

```
┌─────────────── AI 赋能量子 ───────────────┐
│  线路结构 ──► GAT+指针网络（RL 训练）      │
│  校准数据 ──► 7 维噪声特征 ──► 噪声感知布局  │
│  多起点解码 + 局部搜索 ──► 布局候选池竞技    │
└──────────────────┬───────────────────────┘
                   ▼
        天衍-287 真机执行（QCIS 提交）
                   │
┌──────────────────▼───────────────────────┐
│  平台校准数据回流 ──► 设备自归一化特征      │
│  （同权重跨设备零重训迁移）                 │
│  真机测量分布 ──► 映射质量闭环验证          │
└─────────────── 量子赋能 AI ────────────────┘
```

1. **AI → 量子**：强化学习策略网络从线路交互结构中直接学到"好的布局"，替代传统启发式搜索；校准数据作为模型输入，使布局主动规避高误差耦合器（缺陷热区）。
2. **量子 → AI**：真机校准数据回流构成模型的感知输入，使 AI 训练无需在每个设备上重来——**同一权重在不同校准设备间直接迁移**（跨拓扑实验验证）；真机测量分布又作为映射质量的最终裁判，构成"数据→模型→真机→数据"的闭环。
3. **应用侧闭环**：QTrial 优化的线路在金融科技（投资组合优化 QAOA）、材料研发（VQE）等场景落地，进一步验证赋能效果（第七节）。

## 三、问题背景与选题依据

**为什么是量子编译**：天衍-287（祖冲之三号同款，105 数据比特 / 182 耦合器）的 15×7 网格上，任意比特对平均距离 7.33 步（最远 20 步）。一条 100 比特的 QAOA 线路若布局不当，SWAP 数可达数万——以 2Q 门误差 ~0.4% 计，保真度将完全崩塌；而优秀布局可把 SWAP 压缩一个数量级。编译质量是 NISQ 时代"可用性"的第一道闸门。

**为什么是强化学习**：布局本质是 NP-难组合优化（QAP）。传统方法（谱方法、模拟退火、FiDLS 等）只利用拓扑与交互计数；RL 策略网络能从海量线路实例中学习"结构 → 布局"的隐式规律，且推理时一次前向传播即可生成候选布局（105 比特 <0.2s），天然适合云平台的在线编译场景。CO-MAP 论文（arXiv:2605.13638）已证明该范式相对 SABRE 的显著优势；本作品在其基础上针对**噪声感知**与**深度**两个真机核心指标做了机制扩展。

**为什么自主实现路由**：qiskit 等外部软件栈在国内生态中的依赖风险（许可、版本、平台兼容）构成实际部署障碍。本作品的路由/后处理/分解全部自主实现并经过等价验证，交付物对第三方编译器零依赖。

## 四、技术路线与方案设计

### 4.1 总体架构

```
OpenQASM 2.0 ──► 自研解析器 ──► 电路 IR + 依赖 DAG
                 ──► 程序图（交互权重 + 时序感知 + 6 维节点特征）
                 ──► RL 布局：GAT 编码 + 指针解码
                 │   （5 采样 + 4 乱序贪心 + 1 贪心 多起点）
                 ──► 自适应局部搜索（两阶段，逐起点精化）
                 ──► 候选池路由竞技（三规则决胜：SWAP/保真度/深度）
                 ──► 自研 SABRE 路由（front layer + 前瞻 + 衰减 + 历史惩罚）
                 ──► 后处理栈（单遍置换折叠 → 消解 → 1Q 优化）
                 ──► 平台基分解（[rz,sx,x,cz]）
                 ──► 输出：映射 QASM + 天衍 QCIS + 指标 JSON
```

### 4.2 关键技术选型依据

| 决策点 | 选择 | 依据 |
|---|---|---|
| 布局建模 | QAP 静态代价 $\sum w_{ij}\cdot 2\cdot d(\pi(i),\pi(j))$ | 与路由 SWAP 数强相关的可学习代理；CO-MAP 论文式 (5) |
| 编码器 | GAT 4 层×8 头（d=128）+ GraphNorm | 交互图稀疏、局部性主导；论文复现最优配置 |
| 训练算法 | REINFORCE + 自批评贪心基线，**稀疏终局奖励** | 奖励塑形会引入偏差；终局奖励 + 基线归一化已足够稳定 |
| 噪声建模 | 距离插值 $D_{eff}=D_{topo}+\lambda_n(D_{noise}-D_{topo})$ | 保持奖励景观平滑；对误差强度线性稳健（第八节实证） |
| 设备特征 | 7 维校准特征按设备自归一化 | 同权重跨设备零重训 |
| 路由器 | 自研 SABRE（公开论文算法独立实现） | 生产级强度的公开机制 + 零依赖 |
| 后处理 | 单遍置换折叠（零残留 SWAP）+ cx/u1 消解 + 1Q 优化 | 路由后 SWAP 的代数精确消除，保语义 |

### 4.3 数理基础（摘要）

布局代价（式 1）、噪声加权距离（式 2）、GAT 注意力（式 3）、指针注意力（式 4）、终局奖励（式 5）、策略梯度（式 6）、交换评分（式 7）、SWAP 共轭（式 8）、U3 的平台基分解（式 9）、乘积保真度（式 10）——全部推导见技术报告 [docs/technical_report.md](technical_report.md)。

## 六、原型系统

1. **命令行**（`python -m qtrail.pure_cli`）：QASM 入、映射 QASM + QCIS + 指标 JSON 出；零 qiskit 依赖；无权重时自动降级启发式阶梯，任何可解析线路不崩溃；
2. **Web 演示**（`python -m qtrail.web`）：粘贴线路一键映射，指标卡 + 布局可视化，供评委现场体验；
3. **平台对接**：QCIS 直接提交天衍平台；`--calibration live` 实时拉取校准（免重训）；预留真机验证协议（原线路 vs 映射线路测量分布对比，阈值 0.98/0.05）；
4. **功能等价验证**（`python -m qtrail.verify`）：≤20 比特精确态矢量、21-28 比特随机采样，保真度断言；
5. **预训练权重**随仓库交付，评测不依赖训练。

## 七、应用场景与落地价值

- **金融科技**：投资组合优化 QAOA 线路（Barabási 随机图 QAOA 为 Benchpress 收录场景）在天衍-287 上执行——编译质量直接决定其能算多大的组合问题；
- **材料研发**：VQE 分子模拟线路的噪声规避布局，2Q 门集中在低误差耦合器；
- **云平台生态**：在线编译是量子云平台的必备组件；QTrial 的 RL 布局（毫秒级推理）+ 自主路由可无缝嵌入国产量子云软件栈，避免对外部编译器的依赖。

## 八、验证方案与结果

### 8.1 验证严谨性（评审维度五）

- **正确性**：96 个测试；态矢量等价（路由/后处理保语义）；优化前后逐位 A/B 回归门禁（优化只加速、不改结果）；
- **数据严谨**：Benchpress（IBM 官方评测基准，656 条，≤105 比特全部纳入）+ MQTBench + QUEKO；全部原始数据逐线路落盘，统计采用均值/截尾(去 10%)/中位数三口径；

- **诚实负面结果**：路由 oracle 终局奖励、深度感知路由器 LexiRoute、后处理感知微调三组实验未获稳健提升——完整记录于技术文档，未选择性汇报。

## 九、诚实的技术边界

1. **运行耗时**：单线路 wall time 约为感知 O3（qiskit 2.x Rust 编译实现）的 50-100 倍（105 比特线路 6-28s vs 0.1-1.4s）——RL 多起点布局搜索与纯 Python 实现的客观成本；绝对耗时对在线编译可接受，且已通过增量更新与 Numba 内核压缩约 2 倍；
2. **大线路层（51-105 比特）是本作品当前最弱的一层**：均值保真度落后于全部基线（0.0089 vs 感知 O3 0.0209、盲目 O3 0.0139、pytket 0.0119）。根因是 qiskit 管线的管线级机制（SabreLayout + VF2PostLayout 布局重标记 + 酉合成吸收）把路由置换完整吸收为 0-SWAP，而我们的后处理栈只做到尾部置换吸收，残留 SWAP 数（均值 1.3 万）把保真度打穿。布局层的真实价值在 ≤50 比特层与机制证据中体现（噪声稳健性、跨设备泛化、对盲目基线的 226/534 胜场）；大线路层的后处理强化是明确的后续方向（技术报告 §9）；
3. **解析覆盖**：OpenQASM 2.0 标准子集（含自定义 gate、ccx、cp 分解）；Benchpress 656 条中 592 条可解析（88 条 >105 比特超出设备规模、64 条含 `cswap`/`cu1` 等冷门门，均已如实跳过）。
