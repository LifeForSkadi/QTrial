## 1. 用户 6 条意见的落实

### 1.1 S1 跨距 CX 不够明显、蓝→红太突然

- 所有 `long` CX 现在常驻发光投影：未高亮时蓝色光晕，高亮后红色光晕。
- 颜色不再硬切：第 96–112 帧按 RGB 插值从 `#4cc2ff` 过渡到 `#ff6b6b`。
- 过渡期叠加 16 帧短促抖动（振幅 3 px，随颜色推进衰减）和一次发光脉冲。
- 跨距 CX 线宽 4.2 px（高亮 5.0 px），普通 CX 保持 3.4 px。

### 1.5 S5 后处理

1. **A1 纵坐标 bug 修复**
   - 原实现用物理比特 `o.q` 当行号（11–95），20 行线路只显示最底部几条，门全部堆在底部。
   - 改用逻辑比特 `o.lq`（0–19，−1 为空位），门的纵坐标与 L0–L19 一一对应。
2. **A1 改为真实分层线路**
   - 每列是一层（`diagram_ops.layer`），13 层窗口；20 行逻辑比特 + 1 行空位。
   - 每层内先画 2Q 竖线，再画 1Q 盒，最后画 CX/SWAP 标签；标签被 1Q 盒挡住时横向让开。
   - 折叠时后续层整体左移一列，视觉上就是“SWAP 被吸收、线路重新贴合”。
   - 已折叠的 SWAP 从线路中移除；当前这一步淡出，避免下一幕又“复活”（v11 遗留问题）。
   - “并入置换”标签从列顶移到被折叠 SWAP 的中点旁，空位↔空位 SWAP 也能明确指出。
   - 底部压缩条注明“含 5 个空位↔空位”，解释为什么有些 SWAP 画在“空位”行。
3. **A3 带 1Q 邻居上下文**
   - 取 A2 输出中 P88/P95 在层 1–8 的真实门：2 个 CX + 后续 RX/H/RX/RX/Z/H。
   - 两个 CX 亮绿发光；其余 1Q 门暗化为背景（近层 0.58、远层 0.36）。
   - 增加 `层 1`–`层 8` 列头与“同一比特上的前后 1Q 门 · 背景”说明。
   - 对消动画保留：第二个 CX 滑向第一个，随后打叉并出现“对消 −2 CX”。
4. **B 带 1Q 邻居上下文**
   - 每条示意行在合并对左右各加一个暗化 1Q 门（H/Z、RZ/T、S/RZ）。
   - 增加“合并前 / 合并后”列标题。
5. **删除 v5**
   - 幕标题、右侧卡片 6、Guard 画布、底部公式全部去掉 `v5`，改为“采用优化后线路”“fidelity(opt) ≥ fidelity(route)”。

### 1.6 S6 底部布局

- 增加一行可视化等式：`SWAP → CZ CZ CZ + 1Q`，右侧大字 `44 × 3 = 132 CZ`。
