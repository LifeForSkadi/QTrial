## 相位多项式侦察（2026-11-13，数学先行阶段）

恒等式验证脚本 scripts/verify_phase_poly_identities.py（31/32 通过，
唯一失败 = 预期反例 P7：sx 穿 cz 不封闭）。验证过程中纠正 2 个
教科书记忆错误（P5 组：H 目标位共轭 CNOT → CZ 而非方向翻转；
H 控制位穿 cz → CNOT 方向翻转）。

11. **全局 rz 重排（cz 域相位多项式）**：rz 与 cz 对易（A2 ✓）但
    rz 不能穿 sx（A11 反例）。heisenberg N16 实测：理想跨段 rz
    合并 389→363（仅 −26 门，3.5%）——rz 组数 363 被 sx 密度锁死。
    预注册判据 +≥5% 不达标。**结论：否决，不实现。**
12. **H 行走（H 沿 cz 骨架传播复制）**：H_b·cz(a,b) = cx(a,b)·H_b
    （B1 ✓）——H 穿 cz 后骨架变 CNOT，回 cz 基需展开 +2 H，无
    cz 域封闭行走结构。**结论：数学否决。**
13. **4 门 u3 模板**：{rz,sx} 的 4 门族 rz·sx·rz·sx = 2 参数
    （α,β）< 3，非通用（ZSXXZ 5 门是最优通用）。qiskit 的 4 门
    游程 = 3 门游程 + 残留 rz，非模板。**结论：数学否决。**
14. **A2 块合成器 = 1Q 膨胀源**（假设被否证）：A2 on 790→736
    （−54 门）——A2 是减 1Q 的。差距根源在上游 fold+relink 产物
    （790 1Q / 82 cz = 9.6 密度 vs qiskit 3.9）。

**定位结论（diag_block_density/diag_a2_ablate/diag_gap_decomp）**：
1Q 差距主体 = 不动点循环把 H 块混入 u3 合成（A2 off 产物 H 块 = 0，
循环消化了全部 H）——qiskit 的 pass 顺序 = H 对消先行、
1Q 合成后行（CommutativeCancellation 在 Optimize1qGates 前）。
下一攻坚 = **H 优先消解**（预注册中，实验 scripts/diag_h_first.py）。

## 部分收益（收编候选，判据未达标但全增益无风险）

17. **H 优先组 v2（仅 H 组件：滑动+H·H 对消+H·rz·H→rx，
    无 commute）**（2026-11-13 裁决）：3 线路全增益
    N16 −3.3%、N25 −2.6%、qft −0.4%，无变差线路——但全部
    未达 +5% 预注册判据。v1 失败因混入 commute 深层推挤
    （台账 #6 重现）。**结论：不达标不立为机制；作为无风险
    微改进收编候选（h_first 参数保留，完整管线验证后决定
    默认开关）。** qiskit O3 序列解剖（builtin_plugins.py）：
    循环 = TwoQubitPeephole → RemoveIdentityEquivalent →
    Optimize1qGatesDecomposition → CommutativeCancellation →
    最小点停止；我们循环组件等价但 CommutativeCancellation
    的 H/X/Z 自逆门全局对消我们只有相邻版——254 差距的
    定位即此（482 vs 736 同输入）。

18. **u3 级游程合并（分解前 u3·u3 矩阵乘）**（2026-11-12 预注册，
    已裁决否决）：预注册判据 qv32 1Q ≤16,500（−26%）、depth
    ≤3600。实测 merge_u3=True：1Q 23,661 vs 22,944（**+717 劣化**）、
    depth 4215 vs 4150——判据全面不达标，按预注册回退
    （merge_u3=False 默认，pass 与验证脚本保留存档）。
    失败机制：分解前 992 对同比特相邻 u3 看似未利用，但 fixpoint
    的 merge_1q_runs 在 rz/sx 层已等价坍缩（输出列表相邻 run

    扰动 fixpoint 动力学（A2 块结构变化 → cz 3917 vs 3914 →

    qv 类真实差距（1Q 22.5k vs 16.1k、depth 4150 vs 3415、
    logf −7.2）机制未解——方向转向 cx 层对消与分解顺序

19. **merge_1q_runs_v2（u3 级完整 run 合并 + 无跨 cz 通勤）**
    （2026-11-12 预注册补充三十七，已裁决否决）：判据 qv32
    1Q ≤17,500。实测 1Q=41,022（基线 22,944 的 1.8 倍）、
    depth=7628——全面不达标，按预注册回退（merge_u3_v2=False

    失败机制：swap/cx 展开的 H 块（3 门 run）不满足收益检查

    H 块吸收的主力——去掉它损失远超 u3 对合并的收益。
    **三连否证的统一结论**（#11/#18/#19）：跨 cz rz 通勤
    （H 块吸收必需）与 u3 结构保持（sx 被 P7 锁死）在 O(m)
    局部 pass 架构内不可兼得；qv 差距的彻底解法 = 重排分解

    commute-cancel，全部在 u3/cx 层、基翻译前）——大重构，
    另立预注册。
