# 定理级正确性文档（2026-11-13）

管线 = 布局 π → 路由（swap 展开）→ 折叠/链化 → 分解（cx→H-cz-H）
→ 1Q/2Q 优化循环 → 重标记。产物 (C', fin)。
本节给出**与数据集无关的普适命题**与证明骨架，以及**机制-结构
映射**（各优化组件的适用域，可分析、可检验）。

## 1. 定理层（普适，不依赖 587 数据集）

### T1 语义保持（交付判据）

**命题**：若管线每个重写步都实现为精确恒等式（B1 表）或带
数值守卫的近似替换（B2 表），则产物满足交付判据
U(C')|0⟩ = Π_fin·U(C)|0⟩（同物理帧，模全局相位）。

**证明骨架**（对 pass 序列归纳）：
- 基步：布局/路由（swap 展开）= 恒等置换的酉等价；fold/relink
  的 swap 删除 + arr 坐标跟踪 = 置换代数（每次交换 = 对两个
  比特应用置换 π↔π'，全线路同时重标记，恒等）。
- 归纳步：每个优化 pass 的输出 U_out = U_in（恒等式精确）或
  ‖U_out − U_in‖_F ≤ √(2d)·√(1−ov)（B2 守卫）。恒等式组合
  保持语义；数值守卫的偏差按 2√2·√(1−ov) 累积（B2 误差界）。
- 终止后 Π_fin 由 arr 合成（折叠置换）与重标记映射合成。
- 数值验证（**口径修正 2026-11-12，学术审查 P1-1——原表述
  "fid=1（587 全样本）"无证据支撑，且与本项目 pending_decisions
  的"未做 587 逐条语义验证"记录矛盾，此处更正**）：
  ① 端到端精确验证：heisenberg N16/N25 全生产路径（含 RL 布局、
  16 种子路由、全部重标记、A2、分解）紧凑子空间 fid=1.000000
  （verify_e2e_production.py / ab_linear_semantics.py）；
  ② 分层抽样审计：11 条（small/medium/med-large/large）态矢量
  等价 + 合法性（audit_pure_pipeline.py，其中 4 条 k≤24 做语义）；
  ③ 稀疏线路扫描：120 条随机小线路管线级 0 语义失败
  （verify9 修复后复验）；
  ④ 大线路（>26 比特精确模拟不可行）：组件级恒等式验证 +
  全样本人机合法性扫描（verify_all_legality.py）。
  **诚实边界：未做 587 条逐条语义验证**（计算不可行）——结论
  依赖 ①②③ 的抽样与归纳推理的互相印证。
∎

**精确性分级**：恒等式部分 = 数学精确（模全局相位——fid 口径
不敏感）；数值守卫部分 = ε-近似（误差界 2√2·√(1−ov)/块）。
两条路径在图 1 的管线 DAG 中分离记录，评审可逐节点核对。

### T2 终止性

**命题**：decompose_to_platform_v2 的不动点循环在有限轮内终止。

**证明骨架**：循环出口条件 = 一轮内所有组件 changed=False
（无重写发生）。每个组件的重写要么 (a) 门数严格减少（对消/
吸收/恒等删除），要么 (b) 有界轮数上限（slide/commute 的
max_rounds 参数）。组合 (a)+(b) 保证：要么总门数递减链有限
终止，要么重排类组件到达轮上限后不再触发 changed。实现有
max_rounds=12 的硬上限兜底（实测 ≤4 轮收敛）。
∎

### T3 不劣化（**条件命题**——2026-11-12 学术审查 P1-3 修正）

**命题**：在 `selection_rule="fidelity"`（默认，CLI --rule fidelity）下，
管线产物在对数保真度 log_est_fidelity 上不劣于 v4 基线；在
`selection_rule="swap"` / `"depth"` 下，非劣化条件为"主键
（swap 数/深度）更优**且**保真度不降"，主键严格更优时允许
保真度微小下降（判定门限 ±1e-9 log 单位——乘积口径的
1e-12 绝对容差在大型线路下溢区无效，2026-11-12 审查 P0-3 改）。

**证明骨架**：非劣化开关（mapper._v5_not_worse）——v5 路径产物与
v4 基线同时评测（对数保真度 + 主键），不满足上述条件则回退 v4
产物；回退动作 = 选择 v4 产物，语义保持由 T1 对 v4 路径同样成立。
**注**：审查实测过 swap 规则下 accept 的 v5 产物 est_fidelity
低于 v4（swap 严格更少即接受）——原"任何规则下保真度不劣"的
表述为假命题，此处按规则分别陈述。

### T4 合法性保持（真机可运行）

**命题**：若 C' 通过合法性三重扫描（门集 ⊆ {rz,sx,x,cz,measure}、
cz 端点相邻、比特 ∈ [0,spec.n) 且非禁用、无 swap 残留），
则 C' 真机可执行。

**证明骨架**：扫描项与平台执行模型的对应：
- 门集 = 平台原生门集（tianyan287 规范）→ 每个门有校准误差率；
- cz 相邻性 = 耦合图拓扑约束 → 2Q 门可物理实现；
- 比特范围/禁用 = 设备物理比特约束；
- 无 swap 残留 = 产物无虚拟门。
合法性验证脚本（verify_all_legality.py）对 587 条全样本逐一
执行该扫描——合法性的数学判据与执行模型逐条对应，无推断步骤。
∎

### T5 链调度顺序不变式（路由器，2026-11-13）

**命题**：设路由器输入 C（逻辑比特，不含 swap），输出 R（物理坐标
+ 路由 swap + 末尾 measure）。沿 R 的 swap 做内容追踪
（content[p] = 当前物理位 p 上的逻辑比特，初值 = layout 的逆），
把 R 的非 swap 门映射回逻辑比特得到 R̂。则：
(i) 对每个逻辑比特 q，R̂ 中 q 的门序列与 C 中 q 的门序列**逐门相同**
（门名/参数/相对顺序），每门恰发射一次；
(ii) 内容末态映射 = 路由器返回的 final_layout（作为 物理位→逻辑 的
映射）；
(iii) 1Q 门 k 附着于链 C_h **当且仅当** deps(k) ≠ ∅ 且
deps(k) ⊆ chain_set(C_h)；空依赖门进入前沿后立即可执行，不被任何
链延迟。

**证明骨架**：
1. deps 由 last_2q 前向跟踪构建，只记录"链头或独立 2Q 门"——链成员
   被跳过（不更新 last_2q），故 deps 是程序序更早的 2Q 门集合，
   DAG 无环；路由 swap 不改变该 DAG（qiskit apply_swap 语义）。
2. 主循环每轮把 exec_now 按 sorted 程序序发射；1Q 门执行条件恒真
   （`_nq[i]==1`），故空依赖 1Q 门在初始前沿按程序序一次发完。
3. 唯一可能反转同比特顺序的路径：门 g 随链延迟，而同比特更晚的
   g' 抢先发射。若 g' 触发"空依赖立即执行"，则该比特此前无任何
   2Q 门 ⇒ g 也只能是空依赖 1Q 门（若 g 是 2Q 门或 deps 非空，
   g' 的 last_2q 非空）——与第 2 条矛盾。若 g' 的 deps 非空，其
   前沿插入条件（deps 清空且 owner=-1）要求 g 所在链已执行，而链
   执行块按 [head, tail] 程序序发射 g。故顺序保持。
4. 附着条件 (iii)：`deps(k)` 非空排除"空集 ⊆ 任意集合"的数学巧合
   （2026-11-12 P0 的根因）；deps(k) ⊆ chain_set 保证等待该链安全
   （全部前驱在该链块内发射）。
5. 内容末态 = final_layout：router 的 pos 数组语义
   （pos[逻辑]=物理、inv[物理]=逻辑）与内容追踪同构，逐步一致
   （测试断言相等）。
∎

**代码锚点**：router.py deps/链构建（L217-253）、前沿与执行块
（L284-457）、swap 发射与坐标更新（L715-760）；numba 内核
router_kernel.py 头注释声明同款不变式（ab_router_kernel 18/18 逐位
一致）。
**防复发映射**：2026-11-12 P0（空依赖 1Q 门误附着 → 同比特顺序
反转，交付重叠 0.484）由 (iii) 的 `deps(k) and` 修复。
**检验**：tests/test_invariants_property.py::
test_router_schedule_order_property（随机 12 种子逐比特门序 + 动态
恢复线路逐态等价 + 内容末态=final_layout）、::
test_router_empty_dep_1q_regression（最小复现族）。
**测试方法注记（2026-11-13）**：原始 routed 电路的门标签是**发射
时刻**物理坐标，不能用静态 final_layout 逆映射做语义锚点（|0⟩ 输入
上巧合成立 fid=1，随机输入态 fid=0.0024）；正确锚点 = 沿输出 swap
的动态内容追踪。

### T6 坐标帧不变式（fold 类候选，2026-11-13）

**命题**：设 R 为路由产物（门标签 = 物理坐标），fin 为 final_layout
（逻辑→最终物理位）。fold_and_relink(R) 返回 (F, arr)：
- arr ≠ None ⇒ 以 flb[k] = arr[fin[k]] 作为候选 final_layout 时，
  F 与 R 在逻辑空间逐态等价；等价地（物理帧）U_F = P_arr · U_R，
  其中 P_arr 是按 arr 重标记末态的置换。恒等布局下 flb 为恒等，
  F 作为算子等于原始逻辑线路。
- arr = None ⇒ F 就是 R 本体且 R 未被逐门修改（无收益/放弃折叠）。
**不存在**"保留 swap 的折叠产物"这一形态。

**证明骨架**：
1. 折叠单遍 = 把每个 swap 向右穿过其后所有门（对门标签应用该交换）
   + 删除 swap——置换代数恒等式，所有 swap 累积为末帧 P_arr，故
   U_F = P_arr · U_R。
2. 长程门链化（noise_aware_chain）= 每门 4(d−1) 个 cx 的精确恒等式；
   cz → H·cx·H 精确 ⇒ 链化不改 U。
3. 候选 final_layout 组合 flb = arr∘fin 即帧校正（arr[fin[k]] = k 的
   内容初坐标）；_unmap 后逻辑空间逐态等价。
4. 成本守卫触发时必须**整体放弃**（返回输入本体）：若保留 swap 的
   同时更新 arr，同一物理交换被应用两次（内容坐标与物理坐标混用）
   ——该形态无法局部修复，且与内容初始坐标约定互斥（负结果台账）。
∎

**采用条件（结构事实，2026-11-13 测试发现）**：吸收守卫要求
swap(a,b) 之后每个触碰 a/b 的 2Q 门在 arr 调整（a↔b）后仍相邻。
恒等布局下随机 routed 产物的每个路由 swap 之后必然跟着"内容坐标
远距离"的原始门 ⇒ 采用率 0/60（qft5/ghz10/qaoa12 与随机小线路）；
可吸收的最小形态 = swap 后只接内容相邻门（不相交边 swap + 同对
2Q 门，测试构造 12/12 采用）。该事实解释了 fold 候选在管线中的
低采用率，也是"保留 swap"分支无法局部修复的结构原因。
**代码锚点**：post_v2.fold_and_relink（L1717-1809）；候选组合
mapper.py（L296-307）。
**检验**：tests/test_invariants_property.py::
test_fold_coordinate_frame_property（合成可吸收形态：帧恒等式 +
链化合法）、::test_fold_abandon_no_side_effects（真实 routed 产物
放弃路径：返回本体、零修改）。

### T7 重标记双射（C1：noise_aware_relabel，2026-11-13）

**命题**：设 final_layout 为单射（逻辑→物理位），layout 同。
noise_aware_relabel 的每次接受移动 p → p′（p∈used，p′∉occupied；
occupied = 全部 ops 触点 ∪ measures ∪ final_layout 值 ∪ layout 值）
是把 p 的全局标签置换为 p′：
(a) 移动后 final_layout 仍为单射（值两两不同），layout 同步；
(b) 所有 2Q 门端点相邻（接受前检查 all(adj[p′, x])）；
(c) 边误差和严格下降 ⇒ 总（log）保真度单调不降；
(d) measure 标签随同一置换同步。
**证明骨架**：occupied 是当前全部被占物理位的集合，p′∉occupied
⇒ 无其他逻辑比特占用 p′ ⇒ 单射保持；对每条 inst 同步替换 qubit
标签 ⇒ 全局置换（酉等价）；(b)(c) 由过滤/接受条件直接给出；
(d) 由 measure 同步循环给出。∎

**防复发映射**：2026-11-12 P0（used 仅由 2Q 门填充 → 移动目标撞车，
final_layout 出现重复值 {0:2,1:1,2:2}）由 occupied 全集修复；
2026-11-13 P1（measure 不同步）由 (d) 修复。
**检验**：tests/test_invariants_property.py::
test_relabel_bijection_property（真机拓扑/校准、BFS 连通片、一个
2Q 孤立位专测 occupied 全集；双射 + 标签域 + 相邻 + 语义 + 单调）。

**组件注记（A2 2Q 块合成，2026-11-13）**：默认后端改为自研
Weyl/Vatan-Williams 3-CX（`qtrail/pure/weyl.py`）。数学 = KAK 定理
（Vatan-Williams, PRA 69, 032315；Drury-Love, arXiv:0806.4015 的
分解算法）+ 每块重建守卫（|⟨U_synth,U⟩|/4 > 1−1e-8，失败回退自研
torch 路径），故属 T1 的恒等式类组件（B1）；唯一近似来源是 Weyl 腔
退化类（PartialSWAP/fSim 等）规范化的 1e-9 保真度容差，由守卫把关。
单元验证：tests/test_weyl_synthesis.py（260 条随机 SU(4) + 特殊门 +
零 qiskit 子进程断言）。

## 2. 机制-结构映射（适用域可分析）

每个优化组件的触发条件（类型无关、不含线路特判）与其收益结构
的对应——回答"哪些线路结构受益"（实例空间分析，Smith-Miles 2014
框架）：

| 组件 | 触发条件（结构） | 收益结构 | 适用域 |
|---|---|---|---|
| 路由器（RL+联合选择） | 任意（图学习特征） | swap 数 | 全类型（训练分布内） |
| fold/relink | 有 swap 的路线 | 2Q 数 | 全类型 |
| chain_long_gates | 长程 cz | 合法性（链化） | 全类型 |
| merge_1q_runs + u3 分解 | ≥2 门同比特 1Q 游程 | 游程压缩 ≤5 门 | 1Q 密集段 |
| _absorb_h（H·rz·H→rx） | H 块夹 rz 的 7 门窗口 | −2 门/窗口 | 含 cx 分解的线路 |
| _cancel_adjacent_h | 相邻 H 块对 | −6 门/对 | cx 富集段 |
| commute_rz_through_cz | 段边界 rz 对 | rz 合并 | 段间 rz 对齐结构 |
| _cancel_cz_global | 同对 cz 偶次重复 | cz 对消 | 块状/对称线路 |
| slide_x_through_cz + sx 对合并 | sx 对 + cz 邻接 | 打通段边界 | heisenberg 类 |
| A2 块合成（3-cz 块） | ≥5 门同对 2Q 游程 | twoq/深度 | 块状线路 |
| 噪声感知/学习式重标记 | 任意（图同构搜索） | fid（噪声加权） | 全类型 |

**适用域的可分析性**：每个触发条件都是**语法级结构谓词**
（门类型序列模式），不依赖线路语义/生成分布——任何线路要么
满足（收益保证）要么不满足（pass 跳过，无副作用）。因此
"优化不普适"的风险被分解为：**触发条件覆盖范围**（可枚举
结构模式）与**参数泛化**（路由器——由 587 分层数字检验）。
前者的完备性 = 与 qiskit O3 pass 集逐项对照（差距即缺失机制）；
后者的边界 = 分布外测试清单（第 3 节）。

## 3. 分布外测试清单（587 之外的检验）

**目的**：验证触发条件覆盖与参数泛化的边界，不改变正确性结论
（T1-T4 与数据集无关）——只检验性能层。

1. **Clifford 密集**（随机 Clifford 电路，深度 2n~5n）：
   大量 sx/H 与 cz 交织——H 消解、恒等删除的极端压力。
2. **T 密集**（随机 {H,T,CNOT} 或 {H,S,CNOT}）：θ=π/4、π/2
   角度对齐——游程合成的角度特例路径。
3. **不同 ansätze**：QAOA p=1..4（不同 β/γ）、VQE UCCSD 变体、
   QFT 变长（N=8..64）——参数分布转移。
4. **随机 SU(4) 块**（KAK 生成）：A2 块合成的拟合压力
   （拟合收敛率与守卫触发率）。
5. **含测量/经典控制**：mid-circuit measure + c_if——measure
   同步（P1-1 修复的回归面）。
6. **病态结构**：超长 1Q 游程（>50 门）、全连通子图密集 cz、
   单比特线路、两比特线路——游程合成与块收集的边界。
7. **拓扑压力**：线路图与耦合图低匹配度（随机布局最差情形）——
   路由器与链化的极端。

每项执行：合法性三重扫描 + 紧凑子空间 fid（≤26 比特全空间，
更大规模抽检）+ 门数/fid 与 qiskit O3 对照。

## 4. 与 587 分层数字的关系

定理层（T1-T4）保证正确性与合法性——不依赖数据集；
587 分层数字 + 分布外清单检验**性能层**的参数泛化；
机制-结构映射表给出**适用域的可分析表述**（哪类结构受益、
为什么）。
三层分离 = 报告书叙事结构：正确性（数学）→ 性能（测量）→
适用域（结构映射）。
