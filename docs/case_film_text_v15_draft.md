## 1. 本版改了什么

- **读音**：CX 念“C叉”、SWAP 念“斯瓦普”、Qiskit 念“Q斯kit”；“重标记”改为“重新标记”，强制读 chóng。
- **后处理对点**：按 A1 折叠 → A2 门块合成 → A3 CX 对消 → B 单比特门 → C1/非退化门 五段重新排，每句只在对应动画里说。
- **页面过渡**：新增“所以”“接下来是布局”“布局只是把起点摆好”“接下来交给后处理”“那 44 个 SWAP 去哪了”“这些线路都上了天衍真机”等衔接。
- **审计**：改为“v8 发布前抽检三十一条线路，合法性全过”，说明发布对象与审计方式；不再强调“不是真机执行”。
