## 7. 路由器评分重写（2026-11-10 深夜，inj 差距根因修复）

**发现（逐条数据核算 + 与 qiskit 2.5 源码逐项对照）**：
- inj 侧 twoq 精确 = 3×swap+原门（clifford_100: 39581 = 3×11727+4401），
  无块合并——inj 差距主体不是后处理，是**自研 SABRE 多插 3-6 倍 swap**
  （clifford_100 71388 vs ~11727；adder_8 437 vs ~100）。
- 六个偏差（qiskit 2.5 LightSABRE 对照）：
  ① 扩展集权重 0.5 → 应为 0.5/spec.n（高估 100 倍）
  ② 门权重 0.5^t 衰减到 0 → 评分退化平局 + 确定性 argmin → 换位死循环
     （gf2^16 实测 100001 swap 触顶；qiskit 恒权 1）
  ③ 无界历史惩罚 → 后期主导评分（gf2^7 1425 swap vs 271）
  ④ 无随机平局裁决（qiskit 用 seed 做平局随机）
  ⑤ 无防卡死逃逸（qiskit attempt_limit=10n 随机换边）
  ⑥ 单试验 vs qiskit 预设 O3 的 20 trials 取最优
- 另有：前沿门按 set 任意序执行 → 应按 DAG 拓扑序（qiskit 语义）；
  候选边应取 F∪E 邻域（原仅 F）。
- qiskit O3 预设 = SabreSwap(heuristic="decay", trials=20)（VF2PostLayout
  在给 initial_layout 时跳过）；decay 评分 = Σ_F D + (0.5/n)·Σ_E D，
  恒权、最近使用禁忌（decay(0.001,5)，窗口 5）、10n 逃逸。

  拓扑序执行 + F∪E 候选 + 种子随机平局 + 10n 逃逸 + trials 参数 +
