## 0. 总体判断：旧图错在哪

不是"画得糙"，是**三处结构性错误**：

1. **每张图都是六系列分组柱。** 6 种方法视觉权重完全相等，读者没有视线入口。报告真正要论证的只有两方：本方案 vs 最强基线（噪声感知 O3），偶尔 vs 盲目 O1。
2. **图内自带标题（"图 5.2 分层估计保真度对比（均值口径，584 条线路）"）。** 论文图的标题属于图注，不属于图像；图内标题会让同一张图无法复用到 PPT。
3. **对数刻度柱从 10² 起画。** 柱长编码的是"值减去 100"，不是值本身——这是截断轴造成的量级谎报，`antipatterns.md` 里列为严重级。

**统一的修法**：主角两色实心、配角压成浅色；直接标注代替图例；每张图只承担一个论点；图内不写标题，只写面板字母与数据标注。

## 1. 视觉系统（14 张图共用）

| 项 | 取值 |
|---|---|
| 画布 | 纯白 `#FFFFFF`，无边框 |
| 中文 / 拉丁字体 | 微软雅黑 / Arial（字体族回退） |
| 正文与标注字号（落版） | 150–160 mm 图 **9 pt**；123–150 mm **9.5 pt**；<120 mm **10 pt** |
| 轴标签 = 刻度 = 图例 | 一律比正文小 0.5 pt |
| 线宽 | 轴线 0.6 pt，数据线 1.0–1.6 pt，参考线 0.5 pt 虚线 |
| 数据色（语义固定） | 本方案 `#1C4885`；噪声感知 O3 `#C97C1E`；pytket `#2F6B4F`；噪声感知 O1 `#8FB3D9`；盲目 O3 `#B9A67A`；盲目 O1 `#A88CA0` |
| 概念图双色语汇 | **深蓝 = 量子/硬件侧**，**琥珀 = AI/学习侧**，灰阶承担其余结构 |
| 面板字母 | 小写加粗，`a`/`b`，置于坐标区左上外侧 |
| 导出 | 每图 PDF + SVG（可编辑）+ PNG 300 dpi，尺寸 = 报告书图位实际宽高（**1:1 落版，不缩放**） |

## 3. 概念图（4 张）

### 研究逻辑链（先于图形）

1. **问题**：线路要上真机，必须把逻辑比特映射到物理比特；芯片噪声非均匀（边错误率、读出率、T1 逐比特不同），所以"拓扑最短"≠"执行最保真"。
2. **为什么难**：布局是 QAP，NP 难；既有方法要么只按拓扑距离（盲目），要么用一次性静态排序（噪声贪心），都无法在"距离 × 噪声"的联合空间里搜索。
3. **为什么用 AI**：布局是序列决策，代价不可导、非凸；强化学习可以在**稀疏终局奖励**下直接优化最终指标，且图神经网络对图结构同构，策略可跨拓扑迁移。
4. **方法三步**：学习布局（QAP→MDP）→ SWIFT 路由 → 置换重写后处理。
5. **证据**：分层 / 缺陷 / 跨拓扑 / 布局贡献 / 真机。
6. **边界**：大层均值仍低 17.6%；优势是读出感知的；bv 星形族不可约。

四张概念图分别承载第 1+3、2、3、4 条中的一段，不重复讲全链。

### 图 3.1 系统总体架构图 · 159.6 × 87.4 mm

- **论点**：一条五段主链 + 三条支撑链；**三个自研件（布局 / 路由 / 后处理）是重心**，噪声感知作为一条贯穿机制横切全链。
- **图型**：左→右主链（实心块 = 自研，描边块 = 常规环节），顶部输入汇入，底部两条细线支撑轨道，一条琥珀色虚线自校准信息垂直贯穿并标 `D_eff`
- **被否**：旧图的四层横带 + 15 个圆角框——所有元素等权，读者不知道看哪里
- **构图约束**：框内文字 ≥ 4 个字一律移到框外做标注，框内只放阶段名与编号

### 图 4.1 强化学习布局的数据形态变换 · 138.4 × 62.6 mm

- **论点**：一份 QASM 被同时转换成"程序交互图（带权）"与"设备耦合图（带噪）"，两路 GAT 编码后由指针网络**逐比特序贯分配**，产出一个布局。
- **图型**：三段式——左：线路 + 程序图（6 节点带权）；中：双 GAT 编码堆叠；右：**指针解码的 4 帧胶卷**（第 1/2/3/n 步已分配比特高亮），末端接候选池
- **被否**：旧图的"框套框流程 + 三个大箭头"——没有画出"序贯"这个关键机制
- **色彩**：蓝 = 量子线路/图结构，琥珀 = 学习组件

### 图 4.2 策略网络训练流程 · 160.0 × 76.3 mm

- **论点**：REINFORCE + 自批评贪心基线；奖励**只在终局给一次**，所以整套训练必须靠"同批贪心 rollout"当基线来降方差。
- **图型**：左：环形回路（策略 → 采样 rollout → 终局奖励 → 贪心 rollout → 优势 R−b → 梯度更新）；环上把"T−1 步无信号"画成一段长灰条，奖励钉在末端；右：训练数据构成两条 100% 堆积条（ER/线路池 50/50；规模 50/30/20）
- **被否**：旧图的流程图——它把训练画成一条直线，丢掉了"基线是为了抵消稀疏奖励方差"这个因果
- **标注**：89 轮收敛（400 轮预算）、batch 512、4096 实例/轮

### 图 4.3 噪声感知：相同拓扑距离 ≠ 相同代价 · 144.7 × 71.6 mm

- **论点**：两个耦合器的拓扑距离都是 1，但一个是低噪、一个是高噪；`D_eff = D_topo + λ(D_noise − D_topo)` 把这个差别写进代价，布局因此改变。
- **图型**：三段并列——a 两条迷你链（低噪 / 高噪，同 D_topo）；b 距离合成公式；c 同一设备子图上的两个候选布局与各自代价（A 绕开热区 → 低；B 直穿 → 高）
- **被否**：旧图的三框对照——公式与结论都在图外，图内没有可读的因果
- **必须出现**：真实天衍-287 八比特子图（qubits 0–3 / 7–10，边 `[0,7][0,8][1,8][1,9][2,9][2,10][3,10]`），不画假拓扑

## 4. 需要向作者确认的两处口径
