## 备注

- API Key 只用于 SDK 登录，不等于 287 机时额度；即使 `.tianyan_key`
  可登录，paid 机器仍会返回“机时不足”。
- 若拿到有额度的 key，直接设 `TIANYAN_LOGIN_KEY=<key>`，用
  `scripts/real_machine_v8_submit.py --machine tianyan-287` 即可补跑。
