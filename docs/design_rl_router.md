# 设计文档：噪声感知、规模可迁移、链-交换联合动作的 RL 路由

> 状态：设计评审稿（2026-08-22）
> 目标：≤200 比特线路映射优化，单线路 ≤1 分钟，SWAP/深度/保真度三指标至少追平盲目O3，任意拓扑生成可执行优化线路
> 预算：7 天实现
> 原则：不跟随 qiskit 的工程积累路线，走算法创新；实现基于本地分支 wip/improvements-v6 的资产

## 0. 需求与现状

| 需求 | 现状（bench v6 诚实口径） |
|---|---|
| ≤200 比特 | 管线 105 比特 5-30s，numba 内核 ~50μs/交换，线性外推可行 |
| ≤1 分钟 | 需控制策略介入次数（见 §3 子目标分层） |
| ≥盲目O3（三指标） | SWAP 落后（O3=0）、深度 2-8×、保真度均值 0.65×——差距全部来自 0-SWAP 机制缺失 |
| 任意拓扑可执行 | ✅ 已由硬件可执行后处理 + 多拓扑测试保障 |

关键判断（bench6 数据）：布局质量已局部优于对方（qft 有效 2Q 误差 2.4e-3 vs 对方 3.7e-3）——**门数打平即保真度反超**；门数差距 = 残余交换展开（每交换 3 CX）vs 对方的 0-SWAP。

## 1. 创新定位（对照文献空白）

基准文献：[QAP-Router](https://arxiv.deeppaper.ai/papers/2605.12365v1)（Nguyen/Kulshrestha/Safro/Liu，arXiv:2605.12365，2026-05）：路由即动态 QAP 的 RL，reward = QAP 目标变化量，solution-aware Transformer 主干；相对工业编译器 CNOT 减少 **MQTBench 15.7% / AgentQ 30.4% / QUEKO 12.1%**。其自述局限 = 每规模单独训练、大比特未验证、无噪声项、纯交换动作。

本设计的四个填补点：

| QAP-Router 缺口 | 本设计 | 依据 |
|---|---|---|
| 无噪声感知 | **噪声感知 QAP 耦合 + 噪声边权塑形**（VQM 的学习化） | VQM 仅启发式；RL 噪声路由无先例 |
| 每规模单独训练 | 设备编码器 = 7 维 min-max 归一化特征（现有），**一个策略覆盖任意拓扑/规模零重训** | 本项目跨拓扑泛化已验证 |
| 动作只有交换 | 动作 = {交换边} ∪ {前沿 CX 的链展开}——**链-vs-交换被学习而非手设门槛** | 文献无先例 |
| 训练目标 ≠ 评测口径 | 终局奖励 = **路由后经完整后处理栈的真实代价**（2Q 门数 + 估计保真度） | postfid 教训的正解 |
| 布局-路由分离 | 布局候选评分 oracle 换成新策略；布局策略用新 oracle 轻量微调 | 贡献 6 负结果的翻案机会 |

## 2. 策略架构

```
状态：
  逻辑侧 ── 程序图 GAT（现成权重暖启动；编码前沿层+扩展集交互结构）
  物理侧 ── 设备 GAT（现成权重；7 维噪声特征，规模无关）
  耦合项 ── 流矩阵 × D_eff 噪声距离的交互张量进入注意力
           （solution-aware 机制的噪声感知版——与 QAP-Router 的结构性差异）
动作头：
  候选交换边打分（一次前向批量评估全部 ~2N 边）
  + 每前沿长程 CX 的链展开动作打分
奖励：
  稠密塑形 = ΔQAP（交互-距离耦合变化）+ λ·噪声边权惩罚
  终局     = −(后处理口径 2Q 门数 + β·保真度惩罚)
```

训练管线：**离线回放 → 行为克隆暖启动 → 小规模 on-policy 终局微调**。
回放缓冲区由现有快速确定性路由器在图池（1287 图 + Benchpress ≤200 子集）上生成十万级 (状态, 值标签) 对——修复贡献 6 负结果的根源（无快速 oracle、无暖启动、纯 on-policy 方差爆炸）。

## 3. 推理与性能预算（≤200 比特 ≤1 分钟）

- **子目标分层**：策略只在前沿变化点介入（次数 ≈ 门数级，2k-10k 次），决策"下一个要解锁的门 + 是否链展开"；两次决策间由快速确定性 SABRE 执行器向量化执行（现成 numba 内核）
- 预算：10k × 5-15ms（GPU 批量前向）≈ 边缘；宏动作间距 K 可调，目标 ≤25s；加布局/后处理 ≈ 45-55s 达标
- **不劣化开关**：策略滚动劣化即回退确定性基线（下限 = 现有 v6，绝不更差——"追平"承诺的保险）
- 任意拓扑：策略规模无关（设备特征自归一化）；链路径按当前 spec 实时计算；全 2Q 相邻断言测试扩展至 200 比特

## 4. 为什么能追平盲目O3（论证链）

1. **文献背书**：RL 路由超工业编译器 12-30% CNOT——盲目O3 的 SABRE 内核属于被超越的启发式类
2. **保真度双引擎**：门数打平（RL 目标本身）+ 噪声感知路由（交换安排在低误差边；盲目O3 无此项）
3. **训练口径 = 评测口径**：终局奖励 = 后处理后的真实指标
4. **规模迁移**：混合规模图池训练（2-200 比特），200 比特推理零重训

## 6. 诚实风险

- QAP-Router 训练细节不可见（2026-05 新论文），复现收益水平有不确定性；7 天目标 = 追平而非大幅超越
- 终局微调若不稳：退路 = 纯行为克隆 + 稠密塑形（无 on-policy），推理保障不变
- 不劣化开关把下限锁死在现有 v6 基线；负结果也能安全回退（本分支即为此而立）
