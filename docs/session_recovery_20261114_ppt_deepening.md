## 技术事实（均已核对代码/表格，可直接复用）

- QAP：`C(π)=Σ_{i<j} w_ij d(π(i),π(j))`；`D_eff=D_topo+λ_n(D_noise−D_topo)`；`w_e=1+α(φ_e−1)+β·T1_pen(e)`，α=0.5、β=0.1。
- 奖励：`R=−C(π)/Σw_ij`，仅终局一次。
- 策略：程序/设备双路 GAT 各 4 层 8 头 128 维；指针 16 头；已分配掩码。
- 训练：REINFORCE + 贪心自批评基线；4096 实例/轮、batch 512；50% ER + 50% 线路图池；规模 50/30/20；Adam 3e-4 余弦、裁剪 1.0、早停 50；LAUREL 400→89 轮、3.2 s/轮。
- SWIFT 评分（**注意口径**）：`score=Σ_F d + (0.5/n)Σ_E d + (0.5/n)Σ_{L1} d`；0.5 是扩展集/前瞻层权重，**不是逐门衰减**（旧稿曾写错）。前瞻启发式单独贡献 15–20% 交换减少；`w_layer` 层权重实测贡献 38% swap 减少（代码注释）。
- pre_cancel：布局/路由前平台基分解 + 对消；展开后 2Q 数严格下降才采纳（SWAP 记 3 个 CX）。
- 后处理：A1 共轭推挤 / A2 恒等对消 / A3 平台基分解 / VF2++ 精确嵌入；非退化开关以 v4 为基线。
- 主结果：584 条（127/258/199）；0.226 vs 感知 O3 0.226，pytket 0.180（+26%）；胜场 332/515/561。
- 分层：0.7325/0.1460/0.0075 vs 0.7384/0.1404/0.0091；相对变化 −0.8% / +4.0% / −17.6%；截尾深度 101/1006/5739 vs 101/1018/5500；2Q 深度均值 143/4816/2788 vs 124/4102/2263。
- 归因：QFT pre_cancel（logf −21.7/−39.6/−62.1）；graphstate VF2++（2Q 681→120，SWAP 192→5）；大层差距 87% 来自 bv 星形族（逻辑度 36 > 设备最大度 4）。
- 噪声：跨拓扑 0.38/0.33/0.34% vs 盲目 O1 1.64%；缺陷 ×5 时 0.31–0.33% vs 1.10%；LAUREL 布局单独贡献 0.3459→0.4202（+21.5%，29 胜 1 负）。
