# 解除限制后的学习式路由与后处理改进方案（2026-11-11）

背景：上一轮"裸 REINFORCE + 局部特征 + 小训练量"的评分器实验未达验收线
（诊断集 34221 vs 手写基线 10336），与文献共识一致（qgym/Lentini：
稀疏终局奖励在组合性路由目标上失效）。解除限制后（允许任何学习式算法，
仍守三条红线：自产训练信号、非劣化保证、硬件合法性），三条路径如下。

---

## 方案①：自产最优标签 + 模仿学习 + 前瞻奖励 RL（主攻路由差距）

### 1.1 自产最优标签：精确路由求解器（A*）

目标：小线路（n ≤ 10-12）的最优 swap 路由轨迹（专家演示）。

- 状态：当前布局（压缩表示：仅前沿/扩展集涉及比特的位置映射）；
- 动作：耦合图上的合法 swap；
- 代价：swap 数；目标态：全部 2Q 门执行完；
- 可采纳启发式 h = Σ_{前沿 2Q 门} D(π(q1), π(q2)) / 2
  （一次 swap 至多把前沿距离和减少 2，h 永不低估 → A* 最优性保证）；
- 加速：转置表（布局哈希去重）、贪心路由解作上界剪枝、
  门依赖分层（同层门顺序无关）；
- 最优性交叉验证：n ≤ 8 用穷举 BFS 对比；n ≤ 12 抽查与启发式
  下界一致；
- 规模预算：~2 万条（queko287 小档 + 自生成随机小线路），
  单条求解秒级-分钟级，总 < 1 天。

产出物：专家轨迹集（每步选择记录）+ 每条线路的最优 swap 数
（RL 训练的上界参照）。

### 1.2 策略网络（复用现有资产）

- 编码器：复用 QAPolicy 的 GAT（线路交互图 → 逻辑比特嵌入）；
- 动态状态：已执行门掩码、前沿标记、当前物理布局（位置嵌入）；
- 评分头：候选边 (a,b) 的评分 = MLP( [逻辑比特 a、b 的 GAT 嵌入]
  ⊕ [距离分量/步龄/边误差/度/窗口计数] )——现 RouteScorer 的 9 维
  特征作为局部项，GNN 上下文补上"线路结构"维度（上一轮失败点）；
- 推理接口：复用路由器的 scorer 钩子（已实现），贪心 argmin +
  10n 逃逸 + 随机平局不变。

### 1.3 三阶段训练

- 阶段 A（BC 预热）：在专家轨迹上做行为克隆（交叉熵：
  预测专家选的边）。监督信号样本效率远高于裸 REINFORCE，
  无需大算力；
- 阶段 B（前瞻奖励塑形 RL）：奖励 = -(本步 swap 代价)
  + γ·(k 步后前沿距离和的下降量)——每一步都有中间信号
  （LARBE 的 look-ahead reward，正是上一轮缺的东西）；
- 阶段 C（偏置探索）：采样时向"距离和下降最多的候选边"偏置
  （LARBE biased exploration），自批评贪心基线（现有
  reinforce.py 同款）。

### 1.4 验收与失败路径

- 验收线：诊断集（gf2^16 1371 + gf2^32 6477 + dtc_100 4488
  = 10336）贪心评估更低；inj 57 条不劣化；587 抽查不劣化；
- 失败：回退手写评分（scorer=None），零损失；
- 预期：超手写基线概率 40-60%；逼近 qiskit decay 概率 20-30%
  （诚实区间）。

## 方案②：学习式折叠决策（后处理侧，小而稳）

### 2.1 问题

fold_and_relink 的逐 swap 吸收判定目前是手写规则（链成本 < 3 且
d ≤ 6）。该判定有全局影响（吸收置换改变后续所有门的位置），
启发式保守。

### 2.2 学习对象与训练信号

- 打分器 fold_scorer(特征) → 吸收的期望收益（最终 2Q 门数变化）；
- 特征：该 swap 影响的后续门数、各门链化距离、链路径边误差和、
  前瞻窗口内后续 swap 结构、线路进度；
- 训练信号 = 自产密集回归：跑折叠过程时对每个决策点同时计算
  "吸收 vs 不吸收"两条分支的真实最终 2Q 门数差 → (特征, 收益)
  样本对 → 回归。自监督、样本密集、无需外部标签。

### 2.3 部署与验收

- 部署：打分器决策 + 全局守卫（n_2q_new ≥ orig_cost 回退）+
  非劣化开关——任何错误决策都有两层兜底，失败零风险；
- 验收：v7 基线的 2Q 门数再降、态矢量等价测试全绿。

## 方案③：QCIS 门类合成学习（窄而真的展示项）

- 问题：KAK 3-CX 块 → CZ 基分解的相位自由度选择（当前查表缓存）；
- 方法：AlphaTensor 式分解搜索（问题封闭、可枚举验证——正是
  AlphaTensor-Quantum 成功的任务类型）；
- 收益面：窄（预计 1-3% 门数），优先级低，视时间决定。

---

## 三条红线（全部方案遵守）

1. 训练信号全部自产（A* 最优轨迹 / 分支收益差 / 封闭分解），
   不依赖 qiskit 任何输出；
2. 所有学习组件带守卫或非劣化开关，劣化自动回退；
3. 硬件合法性与语义等价保证不变（评分器只影响选择，
   不改变执行语义）。

## 推荐顺序与时间

①（2-4 天，主攻）→ ②（1 天，安全补充）→ ③（可选）。
当前 587/inj 全量在跑，① 的标签生成可与收尾并行。
