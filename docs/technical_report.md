## 摘要

量子线路映射（qubit mapping / circuit compilation）决定一条逻辑线路在真实超导芯片上的执行成本：布局（初始映射）决定双比特门需要多少次 SWAP 才能满足邻近性约束，路由决定 SWAP 的具体插入位置。本项目将布局建模为**二次分配问题（QAP）**，用**图注意力网络（GAT）编码器 + 指针注意力解码器**学习布局策略，以 **REINFORCE + 自批评贪心基线**在**稀疏终局奖励**下训练（CO-MAP 范式）；在此基础上做三项 QTrail 优化：**噪声感知映射**（7 维校准特征 + 噪声加权距离）、**多起点自适应局部搜索**、**深度感知静态奖励**。交付管线完全自主实现（零 qiskit）：自研 OpenQASM 2.0 解析器、电路 IR、SABRE 级路由器（front layer + extended set + 逐门衰减 + 交换历史惩罚）与后处理栈（SWAP 共轭重写 + 消解 + 尾部置换吸收 + U3 平台基分解）。正确性由态矢量等价验证与逐位 A/B 回归门禁保证；性能由增量前沿/扩展集维护与 Numba 融合内核支撑（路由器热循环 5×、后处理 10× 加速，结果逐位不变）。

**最终基准（587 条线路，QTrial pure fidelity 规则）**：平均估计保真度 QTrial **0.1958**、感知 O3 **0.2444**（QTrial 为其 0.80×）、pytket **0.1869**、盲目 O1 **0.1226**；逐线路胜场（534 条全完成）：vs 感知 O3 **29**、vs pytket **134**、vs 盲目 O1 **226**。分层明细见 §8.2 与 tables/final_report/。

**关键词**：量子线路映射；二次分配问题；强化学习；噪声感知；SABRE；稀疏奖励

## 1 问题定义与形式化

### 1.1 量子线路映射

超导量子芯片的耦合器连接图构成一张**设备图** $G_D=(V_D,E_D)$（天衍-287 芯片设计为 105 比特、182 耦合器；**评测设备模型**为 15×7 完整矩形网格，$|V_D|=105$，$|E_D|=188$，见 §1.2 末的拓扑口径说明）。线路中每个双比特门（CX/CZ）都要求其两个作用比特在设备图上**相邻**；不满足时须插入 SWAP（交换两个物理比特上的量子态）把逻辑比特搬近。线路映射因此分解为两个子问题：

- **布局（layout）**：单射 $\pi: V_C \to V_D$，把线路的 $n$ 个逻辑比特放到 $N$ 个物理比特上（$n \le N$）；
- **路由（routing）**：在布局给定的前提下，插入最少/最优的 SWAP 使全部双比特门满足邻近性。

布局质量由 CO-MAP 的静态代价刻画。设程序图 $G_C=(V_C, E_C)$ 为逻辑线路的交互图，边权 $w_{ij}$ 为逻辑比特 $i,j$ 之间的双比特门数。定义

$$
C(\pi) = \sum_{(i,j)\in E_C} w_{ij} \cdot 2 \cdot d\bigl(\pi(q_i), \pi(q_j)\bigr), \tag{1}
$$

其中 $d(\cdot,\cdot)$ 为设备图上的无权最短路径距离（BFS），系数 2 归一为"一条边上的每个交互门需要 2 次交换才能跨越并返回"的物理直观（也即 CO-MAP 式 5 的口径）。**布局问题即最小化 $C(\pi)$ 的组合优化**——这正是二次分配问题（QAP）的加权形式，NP-难，且与路由成本强相关（路由 SWAP 数近似正比于交互门的空间跨度之和）。

**数理本质**：式 (1) 是「交互权重 × 空间距离」的双线性型。$C(\pi)$ 是置换群 $S_N$ 上的函数；布局搜索即在该函数的高维非凸景观上求全局最优。传统方法（谱方法、模拟退火）仅利用拓扑结构；本方法用神经网络学习「程序图结构 → 好的置换」的映射，把组合搜索压进前向推理。

### 1.2 噪声感知扩展

真实芯片的每条耦合器、每个比特都有独立校准误差（1Q 门误差 $\varepsilon_1(q)$、2Q 门误差 $\varepsilon_2(e)$、读出误差、相干时间 T1/T2）。把误差直接并入式 (1) 会使奖励景观过于粗糙（误差数值范围三个量级）。QTrial 采用**距离插值**方案：

$$
D_{\text{eff}} = D_{\text{topo}} + \lambda_n \bigl(D_{\text{noise}} - D_{\text{topo}}\bigr), \tag{2}
$$

其中 $D_{\text{noise}}$ 为边权 $w_e = 1 + \alpha(\phi_e - 1) + \beta \cdot \text{T1}_{\text{pen}}(e)$ 下的全对 Dijkstra 距离，$\phi_e = \mathrm{clip}(\varepsilon_2(e)/\text{median}, 0.2, 5)$ 为误差相对中位数的抬升比，$\alpha=0.5$、$\beta=0.1$；$\lambda_n \in [0,1]$ 控制噪声与拓扑的权重（$\lambda_n=0$ 精确还原 CO-MAP 纯拓扑版）。**数理本质**：式 (2) 保持拓扑主导（奖励景观平滑可学习），同时把噪声做成对距离的**单调扰动**——误差热区在网络距离意义下被"推开"，RL 学到的规避行为对误差强度线性稳健（§8.3 缺陷扫描实证）。设备节点特征为 7 维校准特征（T1/T2/1Q 误差/读出误差/度/行/列）**按设备自身统计 min-max 归一化**——因此同一权重在更换设备（同拓扑不同校准）时零重训练直接迁移（§8.3 跨拓扑实证）。

**拓扑口径说明**（2026-11-09 平台 API 核验后补记）：评测设备模型 = 15×7 完整矩形网格（188 边）+ 合成校准（祖冲之三号公开参数分布），训练与 §8 全部实验均基于此口径。真机实测（`download_config`）为 182 耦合器的弯曲排布（竖边 + "正正反反"周期对角边，与矩形网格边交集仅 98/188），当前可用 168 条 + 4 个禁用比特（Q22/Q27/Q35/Q90），真机校准均值 T1 50.4μs / T2 38.8μs / 1Q 0.07% / 读出 2.4% / CZ 0.53%。评测口径与真机拓扑的差异见 §8.6。

## 2 系统总览

```
输入 QASM ──► [1] 自研解析器（OpenQASM 2.0，qelib1/ccx 展开）
             ──► Circuit IR（指令列表 + 惰性依赖 DAG）
             ──► [2] 程序图构建（交互计数加权 + 时序感知 + 6 维节点特征）
             ──► [3] RL 布局：GAT 编码 + 指针解码（多起点：5 采样 + 4 乱序贪心 + 1 贪心）
             ──► [4] 自适应局部搜索（两阶段，每个起点独立精化）
             ──► [5] 候选池路由竞技（RL 候选 + λ0 拓扑候选 + 启发式 + 平凡布局，
             │        自研路由器实测评分，swap/fidelity/depth 三规则决胜）
             ──► [6] 胜者最终路由（全预算，永不截断）
             ──► [7] 后处理栈（SWAP 共轭推挤 → cx/u1 消解 → 尾部置换吸收）
             ──► [8] 平台基分解（cx→H-CZ-H、U3→[RZ,SX,X]、swap→3×cx）
             ──► 输出：映射后 QASM + QCIS（天衍平台）+ 指标 JSON
```

阶段 [1]-[2] 是表示层，[3]-[4] 是学习层（稀疏奖励 RL + 组合搜索），[5]-[6] 是路由层（自研 SABRE），[7]-[8] 是等价变换层（保语义重写）。除阶段 [3] 的模型推理（PyTorch）与路由器/后处理热循环的 Numba 内核外，全流程为纯 Python/numpy 自主实现，**无任何外部编译器组件**。

## 3 布局层：稀疏奖励强化学习

### 3.1 程序图与特征

程序图 $G_C$ 的节点为逻辑比特，边权 $w_{ij}$ = 比特对双比特门计数；时序感知变体（`temporal_alpha=0.5`）额外累加 $\alpha \times (\text{该交互对出现的去重层数})$（贪心分层后按层集合去重计数），使"跨越多层的持续交互"权重更高（这些交互对深度的影响更大）。节点 6 维特征（CO-MAP 口径）：

1. **单比特门密度**：该比特参与的单比特门数 / 总门数（CO-MAP 原文 η^s_j/η）；
2. **纠缠密度（控制）**：该比特作为控制位的 CX 数 / 总 CX 数；
3. **纠缠密度（目标）**：作为目标位的比例；
4. **影响分数**：4 跳内无向可达比特数占比（布尔矩阵幂，`R_HOPS=4`）；
5. **PageRank**（$\alpha=0.85$）：交互图上的全局中心性；
6. **因果锥**：4 跳前向可达占比（"该比特曾作为控制位"的方向启发式近似——见 `qtrail/problems/features.py` 注释，非严格依赖 DAG 传递闭包）。

### 3.2 图注意力编码器（CO-MAP 复现）

GAT 编码器：4 层 × 8 头，特征维 $d=128$。第 $k$ 头的注意力系数：

$$
\alpha_{ij}^{(k)} = \frac{\exp\bigl(\mathrm{LeakyReLU}\bigl(\mathbf{a}_k^\top [W_k \mathbf{h}_i \,\|\, W_k \mathbf{h}_j]\bigr)\bigr)}{\sum_{j'\in\mathcal{N}(i)\cup\{i\}} \exp\bigl(\mathrm{LeakyReLU}\bigl(\mathbf{a}_k^\top [W_k \mathbf{h}_i \,\|\, W_k \mathbf{h}_{j'}]\bigr)\bigr)}, \tag{3}
$$

仅在图边与自环上求和（掩码注意力）。头拼接后经线性层 + 残差 + **GraphNorm1d**（仅对非填充节点统计，保证变长线路的填充不变性）+ ReLU + dropout 0.1。设备侧 $N=105$ 固定，编码一次广播至全批。

### 3.3 指针注意力解码器

解码器逐逻辑比特生成布局：第 $t$ 步在已放置比特 $\pi_{1:t}$ 的条件下，为下一个逻辑比特选择物理比特。16 头指针注意力，单头：

$$
u_{ij} = C \cdot \tanh\!\Bigl(\frac{\mathbf{q}_i^\top \mathbf{k}_j}{\sqrt{d}}\Bigr), \qquad
P(j) = \frac{\exp(u_{ij})}{\sum_{j' \notin \pi_{1:t}} \exp(u_{ij'})}, \tag{4}
$$

$\tanh$ 经 $C=10$ 截断后做掩码 softmax（已分配比特掩码 $-\infty$）。**数理本质**：指针网络把 QAP 的置换生成变成「上下文条件化的序列决策」，注意力分数即「把逻辑比特 $i$ 放到物理比特 $j$ 的亲和度」；clamp 防止长距离下 softmax 饱和丧失探索。上下文采用 CO-MAP 论文最优的 `concat_project` 变体（当前逻辑比特嵌入与已放置逻辑比特信息拼接投影），QTrial 另有 `dist_ctx` 变体（已放置邻居的加权距离上下文，`ModelConfig` 默认关闭；**交付模型 c0.05（v3 配置）实际开启 `rich_context=true`**）。

### 3.4 REINFORCE 训练

策略 $\pi_\theta$ 采样完整布局后仅获得**终局稀疏奖励**：

$$
R = -\, C(\pi)\, / \sum_{(i,j)\in E_C} w_{ij}, \tag{5}
$$

（按总交互权重归一化，稳定跨实例训练；深度感知变体附加 $\lambda_d \cdot \sum_q h(q)^2 / \sum_q h(q)$ 负载均衡项，紧凑性变体附加 $\lambda_c \cdot$ 布局物理直径——均为终局一次性项，**不破坏稀疏奖励结构**，这是本方法区别于密集奖励 shaping 路线的核心设计。）

策略梯度定理给出：

$$
\nabla_\theta J = \mathbb{E}_{\pi \sim \pi_\theta}\bigl[ (R - b)\, \nabla_\theta \log \pi_\theta(\pi) \bigr], \tag{6}
$$

基线 $b$ 取**自批评贪心 rollout**（同批实例的无梯度贪心解码奖励，Kool 等人方案）：零额外网络、低方差、实现极简。训练配置：batch 512（GT 编码器 256）、Adam lr $3\times10^{-4}$ 余弦退火、梯度裁剪 1.0、200 epoch 预算、验证集早停 patience 20。数据：每 epoch 现生成 ER 随机图（$p=0.3$，规模混合 50% $n\in[5,40]$ / 30% $[41,80]$ / 20% $[81,105]$）与预生成线路图池（MQTBench 36 类 + QUEKO/QASMBench 派生程序图，当前 v4 池 1287 图、规模 2-433，持续扩充）按 config 比例混合。模型约 60 万参数，RTX 5090 单 epoch ~3.3s。

### 3.5 多起点解码与自适应局部搜索

推理时多起点生成候选：5 个采样解码（softmax 采样，多样性）+ 4 个乱序贪心（解码顺序随机置换）+ 1 个普通贪心，按代价去重取 top-10。每个起点再做**两阶段自适应局部搜索**：

- **阶段一（探索，前 30% 预算** $= \text{max\_moves}\times(1-\text{phase2\_ratio})$，`phase2_ratio=0.7`）：以 $p=0.3$ 概率对"热"比特（交互负载 top-25%）做 3 连交换的大扰动，另有 $p=0.1$ 的空位重分配移动（逻辑比特移入未占用物理比特），其余单交换；
- **阶段二（精化，后 70% 预算）**：首改善单交换 + 嵌入定向交换（`embed_prob=0.3`，针对未满足交互对的定向结构匹配）；两阶段共用 patience 50；总步数预算 5000/起点。

代价增量计算：交换只改变受影响比特对的项，每步 $O(n)$ 而非 $O(n^2)$，$n=105$ 单布局 ≤50ms。候选池保持 RL 纯净性（全部为自研构造，无外部编译器输出），经路由器实测评分、fidelity 规则决胜。

## 4 路由层：SABRE 的自主复现

交付路由器为公开论文算法（SABRE，ASPLOS'19）的独立实现，机制完整：front layer 并行执行、extended set 前瞻、逐门衰减、交换历史惩罚（代码见 [qtrail/pure/router.py](../qtrail/pure/router.py)）。

### 4.1 Front layer 与 Extended set

- **Front layer $F$**：依赖已全部满足（依赖集为空）但尚未执行的门集合；其中单比特门与邻近约束已满足的 2Q 门立即执行（每次交换后重新检查——交换可能使某前沿门满足邻近性）。
- **Extended set $E$**：依赖集 $\subseteq F \cup \text{executed}$ 的 2Q 门——即将进入前沿的"下一层"门，用作前瞻信号。

**增量维护**（本实现）：$\mathrm{allowed} = F \cup \text{executed}$ 单调增长，$E$ 的成员资格只会在「某依赖执行」或「某门进入前沿」两个事件时刻翻转，因此在事件时更新、交换迭代零重建——与逐次全量重算逐位等价（§7.3 验证）。

### 4.2 交换评分函数

无门可执行时，在候选边（与前沿门端点相邻的耦合器边）上选取交换 $(a,b)$，评分：

$$
\mathrm{score}(a,b) = \underbrace{\sum_{g\in F} w_g\, d\bigl(\mathrm{after}_{(a,b)}(g)\bigr)}_{\text{前沿项}} \;+\; w_{\text{ext}} \underbrace{\sum_{g\in E} w_g\, d\bigl(\mathrm{after}_{(a,b)}(g)\bigr)}_{\text{前瞻项}} \;+\; \lambda_{\text{ms}}\, \Delta_{\text{ms}} \;+\; \delta \cdot h(a,b), \tag{7}
$$

其中 $w_g = 0.5^{t_g}$ 为**逐门衰减权重**（$t_g$ = 该门被交换触碰的次数，长时间无法满足的门权重衰减、防止被个别"困难门"绑架——SABRE 的核心机制）；$\mathrm{after}_{(a,b)}$ 为交换后的端点位置；$h(a,b)$ 为边交换历史计数（$\delta=0.5$，抑制反复同边交换的振荡）；$\Delta_{\text{ms}}$ 为 makespan 项（$1-$ 交换后新增可执行门比例，SABRE-MS 思想，$\lambda_{\text{ms}}=0$ 还原纯 SABRE）。

**数理本质**：式 (7) 是「当前层 + 下一层」的加权距离一步前瞻和。评分向量化：候选×前沿的距离矩阵 $D[c,f] = \mathrm{dist}[p'_1, p'_2]$ 由融合内核一次循环产出（§7.3），argmin 决胜（同分取最小边序，保证确定性）。

### 4.3 正确性论证

- **终止性**：每步交换要么解锁前沿门（前沿非空时必然存在这样的交换，否则所有前沿门端点已全局不可达，与连通性矛盾），要么降低前沿加权距离和——SABRE 的衰减机制使困难门权重随时间下降、评分景观持续给出可改进方向，实测全部线路终止；实现另设全预算上限（默认 100000，候选评分上限 20000 仅用于筛选、胜者最终路由永不截断）作为兜底。
- **语义保持**：SWAP 是酉变换，交换后执行的门经位置追踪等价于原线路；态矢量等价测试保证（[tests/test_pure.py](../tests/test_pure.py)）。

## 5 后处理栈：置换共轭代数

路由器的 SWAP 往往过度：若干 SWAP 的净效果可能只是输出端的比特置换（可吸收）或相互抵消（可删除）。后处理栈在**保语义等价变换**下系统消除冗余（代码见 [qtrail/pure/post.py](../qtrail/pure/post.py)）。

### 5.1 SWAP 对易重写

SWAP 门 $P_{(a,b)}$ 是比特对 $(a,b)$ 上的置换算子。对任意门 $U$：

$$
P_{(a,b)} \cdot U \cdot P_{(a,b)} \;=\; U^{\sigma_{ab}}, \tag{8}
$$

其中 $U^{\sigma_{ab}}$ 表示把 $U$ 的作用比特按置换 $\sigma_{ab}$ 重标记后的门——这是置换群作用在门集上的**共轭作用**。三条派生规则（A 组）：

1. **不相交对易**：$U$ 不触碰 $a,b$ 时 $U^{\sigma_{ab}}=U$，SWAP 直接后移；
2. **单边触碰重标记**：$\mathrm{SWAP}(a,b);\,\mathrm{CX}(a,c) \;\o\; \mathrm{CX}(b,c);\,\mathrm{SWAP}(a,b)$；
3. **双边触碰控靶翻转**：$\mathrm{SWAP}(a,b);\,\mathrm{CX}(a,b) \;\o\; \mathrm{CX}(b,a);\,\mathrm{SWAP}(a,b)$（CX 在共轭下交换控制/目标）。

单比特门与对称双比特门（CZ、异边 SWAP）同理只做重标记。这些规则让 SWAP 单向穿越线路（**只向后推、不振荡**），在末端与相遇的逆 SWAP 抵消（$\mathrm{SWAP}^2 = I$），或进入尾部吸收。

**硬件可执行性约束**（2026-11-09 修复）：推挤对 2Q 门的重标记受耦合图连通性约束——重写后的端点对必须相邻，否则 SWAP 阻塞不穿。此前版本无此约束，推挤可产生非相邻 2Q 门（态矢量等价测试只查语义、不查连通性，587 条基准的输出线路因此含大量硬件非法 2Q 门）；修复后产物全部 2Q 门落在耦合图上，代价是残留 SWAP 增加（无法吸收的置换保留为 SWAP）。**587 条基准数字为修复前口径**。

### 5.2 尾部置换吸收与重标记

位于线路最末端、其后没有任何门触碰其比特的 SWAP 对最终测量无影响（比特内容在输出端做了交换而已）：直接删除，并把**最终布局**按该置换更新——输出线路的比特标签 = 物理比特，最终布局记录「逻辑比特内容当前在哪个物理比特」，二者共同构成输出的完整语义。这是路由后 SWAP 归零的主要机制。

### 5.3 平台基分解：U3 的 ZXZ 模板

目标平台基为 $[\mathrm{RZ},\,\mathrm{SX},\,\mathrm{X},\,\mathrm{CZ}]$（平台约定：$\mathrm{RZ}(a)=\mathrm{diag}(e^{-ia/2}, e^{ia/2})$，与 qiskit 一致）。QCIS 指令集（依据 cqlib 官方 `qasm2qcis` 表，2026-11-09 修正）：平台原生单比特指令为 `RZ / X2P / X2M / Y2P / Y2M`（`X2P` = X 的 π/2 脉冲 = SX 精确），**无 `X` 指令**；发射器映射 `sx→X2P`、`x→X2P X2P`、`rz→RZ`、`cz→CZ`、测量→`M`，比特标签按平台 `Q1..Q105` 输出。旧版发射器把 sx 展开为 `RZ(π/2) X RZ(-π/2)`（数学上 = Y，且 X 非平台指令），已修正并补矩阵语义回归测试。任意单比特门 U3 的通用分解模板（与 qiskit ZSXXZ 模板逐位一致，数值验证 2.5e-16）：

$$
\mathrm{U3}(\theta,\phi,\lambda) \;\cong\; R_Z(\lambda) \cdot \mathrm{SX} \cdot R_Z(\theta+\pi) \cdot \mathrm{SX} \cdot R_Z(\phi+3\pi), \tag{9}
$$

特例：$\mathrm{H} = R_Z(\frac{\pi}{2})\,\mathrm{SX}\,R_Z(\frac{\pi}{2})$（3 门，与 qiskit 2.5 实测分解一致）；$\mathrm{X}$ 直接映射 $\mathrm{X}$ 门；$\theta=0$ 纯 $R_Z(\phi+\lambda)$。CX → H-CZ-H（目标比特上缠绕两个 H），SWAP → 3×CX 各自展开。

## 6 度量与保真度估计

路由后线路的四个核心指标（[qtrail/pure/metrics.py](../qtrail/pure/metrics.py)）：

- **swap_count**：残留 SWAP 数（后处理吸收后）；
- **depth / twoq_depth**：依赖 DAG 贪心分层的全门层数 / 关键路径上的 2Q 门数（twoq_depth 与芯片 2Q 门时长主导的执行时间直接对应）；
- **估计保真度**（乘积模型）：

$$
F_{\text{est}} = \prod_{g \in \text{1Q}} \bigl(1-\varepsilon_1(q_g)\bigr) \cdot \prod_{g \in \text{2Q}} \bigl(1-\varepsilon_2(e_g)\bigr) \cdot \prod_{m} \bigl(1-\varepsilon_{\text{ro}}(q_m)\bigr), \tag{10}
$$

与 qiskit 支撑版同口径；噪声感知布局的优势即体现为 2Q 项落在低误差耦合器上。候选竞技的三条决胜规则：swap（SWAP 数容差 2 内取保真度最高）、fidelity（保真度 98% 内取 SWAP 最少）、depth（深度容差 $\max(3, 5\%)$ 内取 SWAP 最少）。

## 7 工程实现与性能优化

### 7.1 确定性与正确性门禁

- 路由器候选边按排序遍历、argmin 同分取先——**逐位确定性**；
- **防御性依赖拷贝**：路由过程就地消耗依赖集，候选评分对同一线路对象反复调用——拷贝保证每次调用看到完整 DAG（2026-08-22 修复的跨候选污染 bug，修复前同一对象第二次路由 qft_25 的 SWAP 数从 2033 塌缩到 650）；
- 回归门禁：`scripts/ab_router_v2.py`（路由器 v1/v2 12 用例逐位对比）、`scripts/ab_post_numba.py`（后处理 5 用例 + 200 轮逐位对比）、态矢量等价单测。

### 7.2 向量化与增量更新

- 候选评分向量化（numpy 广播），原纯 Python 循环 qaoa_50 994s → 60s；
- **增量 frontier/extended set**：见 §4.1，交换迭代零重建；
- 候选边邻接表构建（$O(|E_{\text{touched}}|)$ 替代全设备扫描 $O(N^2)$）、交换历史 numpy 矩阵、$O(1)$ 位置更新（inv 映射）。v1→增量版加速 4.5-6.9×，结果逐位不变。

### 7.3 Numba 融合内核

- **`swap_kernel`**（[qtrail/pure/swap_kernel.py](../qtrail/pure/swap_kernel.py)）：候选×前沿距离矩阵单循环融合计算，消除中间 `[C,F]` 数组分配；微基准（C=185, F=120, E=240，105 比特典型规模）**553→109 μs（5.1×）**，与 numpy 花式索引逐位一致（同一 dist 矩阵同一元素的 int64 读取，无浮点差异）；`dist==1 ⟺ 相邻`（无权 BFS 距离）替代 amat 命中计数。
- **`post_numba`**（[qtrail/pure/post_numba.py](../qtrail/pure/post_numba.py)）：push_swaps 流式压实内核（线路 → 并行数组 + 源索引映射，重写不改变门参数故按源索引回填）；qaoa N69 后处理 **1.5s → <0.3s**，200 轮输出逐位一致。
- 无 Numba 时自动回退纯 Python 等价实现（功能与结果不变，仅速度略降），交付零硬依赖。

### 7.4 性能剖析（qaoa_barabasi_albert_N69，69 比特 1551 门）

优化前总耗时 7.66s；优化后 ~6.2s（-19%），各阶段终态构成：

| 阶段 | 耗时 | 说明 |
|---|---|---|
| 解码（多起点 ×2 组） | 3.3s | torch 小算子开销，占比最高，未改动（语义风险） |
| 路由（8 候选评分 + 最终路由） | 2.1s | 增量更新 + 融合内核后 -24% |
| 后处理栈 | <0.3s | Numba 内核后 -80% |
| 局部搜索 + 度量 | ~0.7s | 未改动 |

大比特线路对比（18 条 51-105 比特，单线路 wall time vs 噪声感知 O3）：均值比 84→51.5，中位 52.4，最差 94.1。感知 O3 基于 qiskit 2.x 的 Rust 加速编译器（单线路 0.05-1.4s），纯 Python/numpy 管线存在客观常数差距；QTrial 的绝对耗时（105 比特线路 6-28s）对交互式 CLI 使用完全可接受，且其解码/路由/后处理各阶段仍在独立加速（§9 讨论）。

## 9 诚实负面结果与局限

1. **路由 oracle 终局奖励**（贡献 6）：以真实线路路由成本作终局奖励的四模型头对头中，与静态代价变体差异在运行噪声内——静态代价 + 时序/噪声/深度增强已是强学习信号，oracle 无稳健提升（已完整记录于 tables/research_contributions.md）；
2. **深度感知路由器 LexiRoute**（贡献 7）：前沿分层 + 最短路径候选 + 收益字典序的自主设计，态矢量等价验证通过，但启发式强度仍不敌 SabreSwap 的衰减机制——保留为研究实现并完整记录负结果；
3. **后处理感知保真度微调**（postfid_ft/mt/pure 三变体）：确定性管线 A/B 下均未超越 c0.05 基线——训练目标（静态代价）与管线后处理目标错配，属训练-管线目标错配的负结果；
4. **大线路层（51-105 比特）的剩余差距**（v8 修正口径：均值 0.0072 vs 感知 O3 0.0091、盲目 O1 0.0038）：此前"落后全部基线"的结论部分来自基线未计读出的口径 bug（2026-11-13 修正，台账 #24）。修正后我们优于全部盲目/感知 O1，对感知 O3 在乘积均值上仍低 22%；但该均值 99.9% 由 35 条浅层线路贡献，其中 **87% 的差距来自 bv 星形族**（逻辑比特度数 36 > 设备最大度 4，精确嵌入不可能，SABRE 产生 137–192 次 swap）；164 条深层线路的 log 中位我们更好（−20.5 vs −22.1）。后续方向 = 星形/奇环结构的专用路由（删边嵌入 + hub-aware）与稠密线路门体积压缩；
5. 纯 Python 实现的单线路耗时与 Rust 编译器存在常数差距（§8.5）。

---

## 10 结论

QTrial 在 CO-MAP 的稀疏奖励 RL 布局范式上完成了三项机制扩展（噪声感知、多起点 LS、深度感知奖励），并将交付管线完整自主化（零 qiskit）：自研解析器、SABRE 路由器、置换共轭后处理栈与平台基分解，配合逐位 A/B 门禁与态矢量验证保证正确性，配合向量化/增量更新/Numba 内核保证可用性能。**最终基准（587 条线路，QTrial pure fidelity 规则）**：平均估计保真度 QTrial **0.1958**、感知 O3 **0.2444**（QTrial 为其 0.80×）、pytket **0.1869**、盲目 O1 **0.1226**；逐线路胜场（534 条全完成）：vs 感知 O3 **29**、vs pytket **134**、vs 盲目 O1 **226**。分层明细见 §8.2 与 tables/final_report/。
