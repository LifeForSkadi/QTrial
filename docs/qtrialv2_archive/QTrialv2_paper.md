# HSRL-Map：分层稀疏奖励强化学习的量子线路映射联合优化

> 竞赛作品报告（随实现迭代同步更新 · v0.1 技术框架版）

## 摘要

量子线路映射（布局+路由）是 NISQ 时代量子编译的核心瓶颈。现有方案分为两派：以 SABRE 为代表的启发式方法优化 SWAP 数但深度表现差（深度 2-3× 劣于 tket）；以 tket LexiRoute 为代表的深度字典序路由深度优秀但依赖手工贪心、无学习能力。CO-MAP 开创的稀疏奖励 RL 布局方法仅优化静态代价，与真实路由脱节。本文提出 **HSRL-Map（Hierarchical Sparse-Reward Learning for Mapping）**：一个两层稀疏奖励强化学习框架——布局策略与深度感知路由策略**联合训练**，布局层的终局奖励由路由层的真实成果（深度+SWAP+噪声）定义，形成层级稀疏奖励闭环。理论分析表明深度维度存在调度自由度超级杠杆（同一交换集合的不同调度产生 2-3× 深度差异），贪心路由只能局部利用、学习式路由可全局利用。实验目标：分层评测中深度与保真度逼近/超越 tket，SWAP 显著优于 SABRE O1/O3。

## 1. 问题形式化

### 1.1 基本定义

- **程序图** $P_q = (V_q, E_q, W)$：逻辑比特为节点，双比特门为加权边（$w_{ij}$ = 交互次数）
- **耦合图** $G_Q = (V_Q, E_Q)$：物理比特与连接关系；$\text{dist}(p,k)$ 为最短路径距离
- **布局** $\pi: V_q \to V_Q$（单射）；**路由** $S = (s_1, ..., s_m), s_t \in E_Q$ 为 SWAP 序列
- **分层执行**：线路 DAG 按依赖分层并行执行；前沿 $F$ = 前驱已完成的 2Q 门集合

### 1.2 目标函数（三目标联合）

$$\min_{\pi, S} \; \underbrace{\text{depth}(\pi, S)}_{\text{深度}} \;\; \text{s.t.} \;\; \underbrace{|S|}_{\text{SWAP 数}} \;\text{小}, \;\; \underbrace{-\log F(\pi, S)}_{\text{噪声代价}} \;\text{小}$$

其中保真度乘积模型 $F = \prod_q (1-\epsilon_q^1)^{n_q^1} \prod_{(p,k)} (1-\epsilon_{pk}^2)^{n_{pk}^2}$，$\epsilon$ 来自设备校准数据。

**关键观察（调度自由度超级杠杆）**：固定交换集合 $S$ 后，其**调度**（哪些交换/门并行）使深度在 $[|S|+D_{\min}, 2|S|+D_{\min}]$ 区间内可变化 2-3 倍——深度维度的算法差距空间天然大于 SWAP 维度。贪心路由（LexiRoute）每步局部最优，无法全局利用此杠杆。

## 2. HSRL-Map 框架

### 2.1 两层稀疏奖励 MDP

**布局层**（继承 CO-MAP 范式）：
- 状态 $s^L_t = (P_q, G_Q, \psi_t, c_t)$：程序图、耦合图、部分布局、当前逻辑比特
- 动作 $a^L$：逻辑比特 → 空闲物理比特
- **终局稀疏奖励**：$R^L = -\text{Cost}(\pi)$，其中 $\text{Cost}(\pi)$ = 从布局 $\pi$ 出发路由后的联合代价（见下）——布局只看路由的真实反馈，根治静态代理脱节

**路由层**（本框架的核心创新）：
- 状态 $s^R_t = (\text{DAG}, \text{pos}_t, F_t, D_Q)$：线路依赖图、当前比特位置、前沿、距离矩阵
- 动作 $a^R$：耦合边上的 SWAP
- **终局稀疏奖励**：
$$R^R = -\left(\alpha \cdot \frac{\text{depth}}{D_0} + \beta \cdot \frac{|S|}{S_0} + \gamma \cdot \frac{-\log F}{N_0}\right)$$
其中 $D_0, S_0, N_0$ 为规模归一化因子；$(\alpha, \beta, \gamma)$ 目标权重（默认 $(1, 0.3, 0.5)$，深度第一公民——吸取 LexiRoute 的字典序思想并推广为可学习形式）

### 2.2 层级奖励闭环

$$J(\theta_L, \theta_R) = \mathbb{E}_{\pi \sim \pi_{\theta_L}}\left[\mathbb{E}_{S \sim \pi_{\theta_R}(\cdot | \pi)}\left[R^R(\pi, S)\right]\right]$$

训练：布局策略的每条轨迹奖励由路由策略在该布局下的实际成果定义；路由策略的奖励由真实执行成果定义。两级均为**终局一次性稀疏奖励**（本方法的标志性约束，继承 CO-MAP 与 QTrial）。

### 2.3 为什么学习式路由可超越贪心 LexiRoute

贪心 LexiRoute 的评分是局部字典序 (深度增量, 使能门数)——每步独立最优但**无全局规划**。学习式路由策略在相同状态下可学会：(a) 为后续门提前布局交换（前瞻深度 > 1）；(b) 牺牲短期深度换取关键路径整体缩短；(c) 融合噪声感知（贪心版完全盲）。REINFORCE 的终局奖励提供全局梯度信号，这正是贪心启发式缺乏的。

### 2.4 架构

```
┌─────────────────────────────────────────────────────────┐
│ 布局策略 π_θL：GAT 编码器(P_q, G_Q) → 指针解码器 → 布局 π  │
│         （CO-MAP 架构 + QTrial 的噪声/时序特征）          │
└────────────────────────┬────────────────────────────────┘
                         │ 布局 π
┌────────────────────────▼────────────────────────────────┐
│ 路由策略 π_θR：GNN 编码(线路 DAG + pos_t + 前沿 F_t + 设备) │
│        → 交换边评分 → 掩码 softmax → SWAP 选择            │
│        （状态更新：分层执行模拟器推进，无门可执行时决策）   │
└────────────────────────┬────────────────────────────────┘
                         │
              终局稀疏奖励 R^R = -(α·depth + β·swaps + γ·noise)
              （布局策略的奖励 = 路由成果，层级闭环）
```

**分层执行模拟器**（环境，确定性、快速）：DAG 依赖跟踪 + 前沿判定 + 内容位置追踪——正确性由态矢量等价验证保证（这是 QTrial 迭代中沉淀的核心组件，独立于决策逻辑）。

### 2.5 训练

- 两级策略共享 GNN 编码器族（GAT，4 层 × 8 头，d=128）
- REINFORCE + 自批评贪心基线（QTrial 验证的稳定组合）；布局层与路由层交替更新
- 路由层课程：5-15 比特线路起步（路由序列短、梯度有效），逐步扩展到 25/50
- 数据：v4 级多源池（MQTBench/QUEKO/QASMBench 2-433 比特）+ 随机图

## 3. 理论性质（报告要点）

- **性质 1（模拟器正确性）**：分层执行模拟器输出的线路与原始线路态矢量等价（全局相位不敏感）——实验验证
- **性质 2（深度下界）**：$\text{depth} \geq \text{depth}(\text{DAG 关键路径}) + |S_{\text{必要}}|$——深度优化的理论空间
- **性质 3（稀疏奖励充分性）**：终局奖励对深度/SWAP/噪声三目标给出无偏梯度（REINFORCE 定理），贪心启发式无此性质

## 4. 实验方案

- 分层评测：≤10 / 11-50 / 51-105（满占）三层；基线 SABRE O1/O3、pytket、MQT QMAP
- 指标：深度（均值/截尾/中位）、SWAP、2Q 门数、估计保真度（同一校准数据）
- 功能等价性验证：态矢量等价（≤28 比特）+ 天衍平台真机验证（预留接口）
- 达标线：各层深度与保真度逼近/超越 tket；SWAP 显著优于 O1/O3
